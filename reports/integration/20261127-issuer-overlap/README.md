결제망 두 곳의 합을 16.7%p 낮춘 만큼 어도비 한 곳의 몫이 커졌다. 그룹별 동일가중을 채택할 근거는 이 표만으로 충분하지 않다. 특히 관망을 그대로 반영하면 이 표본에서 두 결제사에 신규 비중을 부여할 근거가 없고, 남은 예산을 어도비에 몰아주는 결론도 나오지 않는다. 현재 가능한 결정은 종목별 조건을 추적하고 미배정 몫을 표시하는 것이다.

재현하려면 기준 커밋에서 `python3 reports/integration/20261127-equity-sleeve/compare.py`를 실행한다. X·X·Y를 위 세 종목 순서로 대응시켰다. 실행 종료 코드 0, HHI 1/3과 3/8을 확인했다. 수치 차이는 그룹 크기와 배분 규칙에서 나온다. 실제 주가 상관, 위험 민감도, 운용성과는 측정하지 않았다. 후속 검증은 동일 시점의 편입 근거가 있는 복수 후보를 확보한 뒤 조건 충족 여부와 집중도를 함께 대조하는 것이다.
