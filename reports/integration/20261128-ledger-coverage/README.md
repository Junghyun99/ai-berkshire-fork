# 판단 원장 전체의 사후 평가 가능 범위

2026-11-28 KST. [coverage.csv](coverage.csv)는 기준 main 8056df5의 원장 100행 전체를 보존한다. 85티커, 관망 95·매수 3·회피 2이며 체크리스트 9행과 심층 분석 91행이다. 의견 라벨과 실제 실행은 별개다.

행별로 최초 원장 등록 main 시각, 당시에 존재한 보고서 경로·커밋·blob·변경 시각, 시장, 의견 유형, 비교안, 벤치마크, 관측 시작·종료, 거래일 수, 기존 사례에서 확인한 범위와 누락 자료를 기록했다. 최초 등록 시 의견·경로가 최신 원장과 일치하는지 검산했다. 최초 등록 시점부터 본 이유는 공개된 보고서가 먼저 존재해도 당시 원장이 이를 포함하지 않았을 수 있기 때문이다.

**두 시간 기준.** 각 시장 현지 등록일 다음 거래일부터 11월 27일까지 계산한 elapsed_sessions는 후속 개정 뒤까지 포함한다. sessions는 보고서 파일의 다음 변경일 전날까지만 센다. 장 시작 전 등록도 같은 날을 제외하고, 장 마감 후 개정도 개정일을 통째로 제외하는 보수적 일 단위 산정이다. 단순 편집도 개정으로 세므로 유효기간의 하한이다. 23행이 이 규칙에서 0일이다. 이미 수행한 사례는 미국 장중 시각을 별도로 확인했으므로 날짜가 다를 수 있다. 거래일 수는 평가 기회이며 관측 가격·사업 신호가 실제 확보됐음을 의미하지 않는다.

미국은 11월 26일 휴장과 27일 단축 거래를 반영했다. 일본은 11월 3일·23일을 제외하고 한국은 해당 구간 평일을 사용했다. 11월 19일 한국 지연 개장은 거래일로 센다. 시장 전체 달력 기준으로 개별 종목의 거래정지는 미검증이다. [NYSE](https://www.nyse.com/markets/hours-calendars) · [JPX](https://www.jpx.co.jp/english/corporate/about-jpx/calendar/)

11개 티커에 판단이 반복된다. 양의 관측창을 가진 77행 모두 같은 시장의 다른 행과 하루 이상 중첩됐다. overlap_rows는 같은 시장의 교집합이 있는 다른 행 수다. 독립 표본 수로 사용하지 않는다. 보고서 하나에 여러 체크리스트 티커가 있어도 원장 ID를 보존했다.

**가격 미도달과 미검증을 구분한다.** #136·#137·#138·#139에서 별도로 재생한 ADBE·MSFT·NFLX의 정확한 원장 3행만 사례에 연결했다. MSFT 축소는 당시 관망 보고서의 조건부 차수다. 교체 사례는 두 원장 행에 걸친 한 건이다. 다른 97행은 가격·사업 조건 도달 여부 미판정으로 남긴다. 공통 창의 표본 수익률로 합산한 사례는 아직 없다. 후속 평가에서는 기간이 충족된 행 전체를 대상으로 당시 조건을 추출하고 원시 시가·종가·배당과 비교 자산을 대조한 뒤 미도달, 조건 충족, 자료 부족을 기록한다. 미도달 행도 현금과 즉시 편입 대안을 같은 기간 추적한다.

전체 Git 이력이 있는 저장소 루트에서 `python3 reports/integration/20261128-ledger-coverage/build.py`를 실행한다. CSV의 start/end는 버전 제한 창, elapsed_windows는 기간만 지난 창, mature_windows는 같은 버전 창이다.
