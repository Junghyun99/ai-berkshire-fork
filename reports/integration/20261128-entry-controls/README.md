## 매매 가정

즉시 편입은 각 창의 첫날 시가, 평가는 다섯째 날 종가를 사용한다. 조건부 대기는 당일 종가가 1차 상한 이하이고 당시 확인 가능한 사업 조건이 충족된 경우 다음 거래일 시가가 상한 이하일 때 진입한다. 시가가 상한을 넘으면 해당 신호는 만료되며 이후 새로운 종가 신호에서 다시 평가한다. 장중 지정가·슬리피지·세금·수수료·이자·환율은 반영하지 않았다. 미확인 조건의 기본 시나리오는 현금 대기다. 원보고서가 요구하는 판단 재검토가 실제로 일어났는지는 별개다.

23건 중 즉시 편입의 가격수익률은 10건 상승·13건 하락이었다. 가격 미도달 19건도 같은 창으로 계산했다. results.csv의 price 열은 배당 제외이며 배당 이력을 점검한 네 사례에만 with_dividend 열을 채웠다. 계산은 (종료가 + 권리 발생 배당금) / 진입가 − 1이다. 배당은 세전 미수금으로 반영했다. 개별 차수 기준의 단기 시뮬레이션이며 시장 벤치마크·실제 계좌성과·전략 우열 추정은 별도다.
