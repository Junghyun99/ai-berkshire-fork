# 같은 주식 예산에서 개별주를 어떻게 조합할까

2026-11-27 · 합성 비교 · D-020

기존 분석 스킬에서 편입 검토 대상으로 선별한 후보가 주어졌다고 가정한다. 같은 후보·같은 주식 예산을 유지한 채 배분 규칙만 바꾸어, 어떤 위험이 어디로 이동하는지 살펴본다. [선행 연구](../20261127-opinion-allocation/README.md)

## 두 가지 배분 규칙

합성 종목 A와 B는 공통 수요 요인 X에, C는 요인 Y에 노출된 것으로 단순화했다. 주식은 전체 자산의 60%로 가정했다. 종목 동일가중은 세 기업에 같은 몫을 준다. 그룹 동일가중은 X와 Y에 절반씩 주고 그룹 안에서 균등 배분한다. 다음 수치는 방법 비교를 위한 가정이며 실제 기업의 측정값이나 정책 한도는 미정이다.

| 측정 항목 | 종목 동일가중 | 그룹 동일가중 |
| --- | ---: | ---: |
| A / B / C, 주식 내부 | 각 1/3 | 25% / 25% / 50% |
| A / B / C, 전체 자산 | 20% / 20% / 20% | 15% / 15% / 30% |
| 주식 중 X 노출 | 66.7% | 50% |
| 종목 집중도 HHI (주식 내부 비중 제곱합) | 0.333 | 0.375 |
| A와 B만 동시에 20% 하락할 때 전체 자산 수익률 | −8% | −6% |
| C만 20% 하락할 때 전체 자산 수익률 | −4% | −6% |

각 충격에서 나머지 자산 수익률은 0으로 놓았다. 그룹을 균등하게 만들면 공통 수요 충격의 손실이 줄지만, Y를 대표하는 기업이 하나뿐이어서 C의 고유 위험이 커진다. 어느 충격이 더 자주 발생하는지에 대한 증거는 이 실험에 없다. 두 방식을 평가할 때 최대 그룹 노출과 최대 종목 노출을 함께 제시한다.

## 실제 후보 조합에 적용하는 순서

1. 동일한 판단 시점에서 원 보고서의 편입 근거·가격 조건·반증 조건을 가져온다. 조건 미충족 후보는 관찰 대상으로 두고 주식 예산 중 배정할 근거가 부족한 몫을 표시한다.
2. 각 기업의 주요 고객·매출원·공급망에서 공통 위험을 식별하고 근거 절을 연결한다. 여러 요인에 걸친 기업은 노출 근거와 불확실성을 함께 기록한다. 단순 그룹 예시를 그대로 적용하려면 배타적인 그룹 정의가 필요하다.
3. 같은 후보에서 두 배분안을 비교한다. 공통 충격이 줄어도 단일 기업 의존도가 커지면 그 교환관계를 기록한다. 다른 후보를 더할 때는 동일한 주식 예산에서 추가 전후를 비교한다. 테마 ETF가 필요하면 기준일별 구성종목으로 직접 보유와의 중복을 합산한다.
4. 수익률 상관 비교에는 당시 이용 가능했던 동일 기간·동일 통화 총수익률을 사용한다. 표본이 부족하면 미확인으로 둔다. 이번 그룹 구분은 추정 상관계수로 사용하지 않는다.
5. 반증·의견 변경·새로운 공통 위험은 편입 또는 제외를 재검토할 사유다. 가격 변동에 따른 비중 이탈은 별도로 확인하고, 재조정 전후의 집중도와 예상 거래비용을 비교한다. 재조정 주기와 한도는 연구 미결이다.

두 규칙은 후속 비교 후보로 유지한다. 다음 실증 단위는 같은 시점에 이용 가능했던 복수의 기업 보고서를 고정하고 위 표의 노출 근거와 미확인 정보를 채우는 것이다.
