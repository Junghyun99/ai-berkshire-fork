# 주식 비중과 개별주 구성 연구

2026-11-27 · 연구 방향 D-020

자산배분 연구로 전체 자산 중 주식 비중을 검토하고, 그 안을 기존 분석 스킬로 선별한 개별주로 구성한다. 특정 종목을 정하기 어렵고 테마 노출이 필요할 때 지수·테마 ETF를 검토한다.

| 단계 | 연구 질문 | 산출물 |
| --- | --- | --- |
| 자산배분 | 전체 자산에서 어느 정도를 주식에 배분할까? | 목표 주식 비중 E와 위험 근거. 현재 E는 미정 |
| 후보 선정 | 어떤 기업이 편입 검토 대상인가? | investment-team 등 기존 분석 스킬의 의견, 가격 조건, 반증 근거 |
| 구성 | 후보를 함께 담으면 어떤 위험이 겹치는가? | 개별 기업·업종 집중도, 중복 노출, 상관관계, 주식 내부 비중 s |
| 유지·재검토 | 어떤 변화가 편입·축소·제외를 정당화하는가? | 논지 변화와 비중 이탈을 구분한 재검토 기준 |

전체 자산에서 한 종목의 비중은 E × s다. 주식 내부 비중을 정할 때에는 다른 후보와 함께 보유했을 때의 위험을 평가한다. 테마 ETF를 포함하는 경우 기초 보유종목과 직접 보유분의 중복을 함께 검토한다. 성과 비교용 지수는 평가 설계 단계에서 선택한다.

**어도비 사례.** 기존 보고서의 매수 의견과 차수별 조건은 후보 검토에 전달할 수 있다. 보고서의 상한 5%는 기준 자산 범위가 미확인이다. 따라서 어도비의 목표비중은 미정이다. [원 보고서](../../어도비/최종보고서.md)

**검증.** verify.py는 원 보고서의 판단·상한과 최종/06 계획 일치를 확인한다. 개별주만 담는 합성 사례와 테마를 포함한 합성 사례에서 주식 비중 합과 총자산 비중 합을 확인했다. 출력 숫자는 산술 예시다. [검증 결과](evidence.json)

다음 연구는 같은 주식 예산에서 후보 조합과 비중 배정 방식별 집중도·위험을 비교하고 편입·제외·리밸런싱 기준을 설계하는 것이다. IPS v0.4는 DRAFT다.
