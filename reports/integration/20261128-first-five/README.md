## 재현 방법과 한계

전체 Git 이력이 있는 저장소에서 `python3 reports/integration/20261128-first-five/build.py`를 실행한다. 원장 커버리지 표의 mature_windows에서 5일 창을 선택하고 각 판단에 고정된 report_blob에서 첫 번째 분할 매수가를 읽는다. 삼성전자는 보고서의 근삿값인 18만원을 재검토 기준으로 사용했다. 체크리스트 판단은 results.csv에 원본 blob과 함께 보존했다. 체크리스트 자체의 선별 성과와 재검토 조건은 후속 연구 대상이다.

bars.csv에는 심층 보고서 23건에 해당하는 거래소 현지 통화 기준 시가·고가·저가·종가 115개 일봉과 행별 Stock Analysis 출처가 있다. 비조정 종가 열을 사용했다. 미국 달러, 한국 원, 일본 엔, 대만 달러를 환산하지 않고 해당 보고서와 같은 단위로 비교했다. 2330.TW는 원장 시장 필드가 US이지만 대만 상장 보통주 가격과 현지 거래일을 사용했다. 가격은 단일 2차 출처이며 독립 출처 대조는 미완료다.

최초 신호는 일별 종가가 기준 이하일 때이며 장중 저가 최초 도달일도 따로 보존했다. 다음 시가는 조건을 확인한 후 시장에서 관측한 참고값이다. 익일 시가가 상한을 넘으면 같은 한도의 매수를 가정할 수 없다. 실제 주문·체결이나 성과 추정은 포함하지 않는다. 후속 연구는 당시 이용 가능한 공시로 세 조건부 사례를 점검하고, 배당·비교자산 자료를 맞춰 즉시 편입·조건부 대기·현금의 동일 기간 성과를 비교한다.
