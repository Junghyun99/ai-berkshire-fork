  - 조정 PER 36.7배는 2021~2025 연말 PER 중앙값 36.05배와 같은 수준이다(추정, 평가이익 제거).

- 실행 계획은 비중 상한 5%다.
  - 분할 매수: 1,100 USD 1.5%(4Q26 영업CF가 순이익 이상·비유동 계약부채 €9.3B 이상 확인 시) → 1,000 USD 1.5% → 809.25 USD 2%(2·3차는 반증 조건 미발생 시).
