## 비컨센서스 발견

1. 팩트시트 PBR 0.77배는 신종자본증권 5,200억원이 포함된 자본 기준이다. 보통주 기준으로는 PBR 0.84배·PER 6.76배다.
2. 2026년 1~3Q 고정이하여신은 +45.1%인데 충당금 전입은 −3.8%다. "사상 최대 이익"의 상당 부분은 충당금을 덜 쌓은 결과다.
3. 지방금융지주 동일인 15% 지분 한도 때문에 자사주 소각이 대주주(삼양사·얼라인) 지분 매도 압력으로 이어진다. CET1 12.39%로 환원율 50% 초과도 검토 기준(13%) 밖이다.
4. 지금은 금리 인하기가 아니다(기준금리 3.00%, 7·8월 인상). 핵심 위험은 NIM보다 외국인·중저신용 차주의 신용이다.
5. 광주은행은 전남광주통합특별시 1금고를 NH농협에 내줬고, 저원가 예금 비중은 2021~2024년 6~11%p 떨어졌다. "지역 독점" 해자는 데이터로 확인되지 않는다.
