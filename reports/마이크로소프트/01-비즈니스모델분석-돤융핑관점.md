## 1. 비즈니스 모델 본질

### 1.1 핵심 사업 정의

데이터에 따르면 마이크로소프트의 매출은 두 축으로 나뉜다.
1. **기업이 매년 내는 "디지털 업무 인프라 통행료"**: M365, Windows Commercial, Dynamics, LinkedIn, 보안. 직원 1인당 과금(per-seat)이고 다년 계약이다.
2. **사용량에 따라 내는 "컴퓨팅 임대료"**: Azure, 서버 제품. 쓴 만큼 내는 소비형(consumption) 과금이다.

여기에 소비자 부문(Windows OEM, Xbox, 검색)이 붙어 있다.

돤융핑식으로 정의하면, 이 회사는 **"세계의 화이트칼라가 출근해서 켜는 모든 것(계정·문서·메일·회의·보안)을 소유하고, 그 위에 연산을 판다."**

### 1.2 세그먼트 손익 (FY2026, 단위 백만 달러, 출처: 10-K FY2026 Note 18, 8-K Ex.99.1)

| 세그먼트 | 매출 FY25 | 매출 FY26 | 성장률 | 매출총이익률 FY26 | 영업이익 FY26 | 영업이익률 FY25→FY26 | 영업이익 비중 | 증분 영업이익률 |
|---|---|---|---|---|---|---|---|---|
| Productivity & Business Processes (PBP) | 120,810 | 139,996 | +15.9% | 82.1% | 83,879 | 57.8% → **59.9%** | **54.0%** | **73.5%** |
| Intelligent Cloud (IC) | 106,265 | 137,791 | +29.7% | **62.2% → 58.0%** | 56,972 | 42.0% → 41.3% | 36.7% | 39.3% |
| More Personal Computing (MPC) | 54,649 | 54,052 | −1.1% | 56.6% | 14,386 | 25.9% → 26.6% | 9.3% | 해당 없음(매출 감소) |
| **합계** | 281,724 | 331,839 | +17.8% | 67.9% | 155,237 | 45.6% → 46.8% | 100% | 53.3% |

(증분 영업이익률 = 영업이익 증가분 / 매출 증가분. 계산은 financial_rigor.py)

**사실 1**: 매출 증가분(501억 달러)의 63%(315억 달러)가 IC에서 나왔다. 그러나 영업이익 증가분(267억 달러)에서는 PBP가 141억 달러(53%)로 가장 컸다.
**사실 2**: IC 매출총이익률은 1년 사이 4.2%p 떨어졌다(62.2%→58.0%). 영업이익률은 0.6%p만 떨어졌다. 차이는 IC 영업비용률이 20.2%에서 16.7%로 낮아진 데서 왔다. 즉 **매출원가(감가상각 포함) 압박을 판관비 레버리지로 메운 것**이다. 판관비 레버리지는 무한하지 않다(관점).

- Microsoft Cloud(M365 Commercial 클라우드 + Azure 등 + LinkedIn 상업 부문 + Dynamics 365) 매출은 FY24 1,377억 → FY25 1,689억 → FY26 2,144억 달러로, FY26 전사 매출의 64.6%다.

### 1.4 성장은 "양(量)"인가 "값(價)"인가

| 사업 | 성장 동력 | 판정 |
|---|---|---|
| M365 Commercial | 좌석 수 증가(성숙기 진입, FY26 좌석 성장률은 **데이터 부족**) + ARPU(E5 업셀, Copilot, 2026-07-01 정가 인상) | **값 주도.** 다만 경기 사이클이 아니라 구조적 가격결정력에서 나온 값이다 |
| Azure | 고객이 쓰는 컴퓨팅 양. 회사 스스로 "공급(용량) 제약"을 밝혔다 | **양 주도이자 자본 주도.** 데이터센터를 지은 만큼 팔린다 |
| Xbox·Windows | 하드웨어 사이클과 PC 시장 | 정체 또는 감소 |

**관점**: 돤융핑의 경고("값 주도 성장은 사이클이 좋아진 신호일 수 있다")는 마이크로소프트에서는 방향이 반대로 작동한다. M365의 값 주도 성장은 사이클이 아니라 해자에서 나오는 가격결정력이다. 오히려 **Azure의 양 주도 성장이 AI 인프라 수요 사이클에 노출돼 있다.** 공급이 제약된 시장에서는 누구나 잘 판다. 공급이 풀린 뒤에도 가격이 유지되는지는 아직 검증되지 않았다.

**결론 ★5**: 사업 정의가 명확하다. 영업이익의 54%가 매출총이익률 82%의 구독 사업(PBP)에서 나온다.
**그러나 다른 한편으로**, 성장의 무게중심은 매출총이익률이 떨어지는 IC로 옮겨가고 있다. FY27에도 전사 영업이익률이 "1%p 미만" 낮아질 것이라고 회사가 가이던스를 줬다(FY26 4분기 콜, MarketBeat 요약).

## 2. 플라이휠: M365 · Azure · GitHub · Copilot · OpenAI

### 2.1 플라이휠 구조 (사실 + 관점)

```
 [Entra ID(계정) · Windows · M365 좌석 450M+]
        │  (기업 데이터: 메일·문서·Teams·SharePoint = Microsoft Graph)
        ▼
 [Copilot / Agent 365 / E7]  ← 기업 데이터 위에서 돌아가는 AI → 좌석당 ARPU 상승
        │  (추론 수요)
        ▼
 [Azure AI Foundry · GPU 용량]  ← OpenAI · Anthropic 모델 + 자체 MAI 모델
        │  (규모 → 단위원가 하락 → 가격)
        ▼
 [GitHub / Visual Studio]  ← 개발자가 Azure 위에서 앱을 만든다
        └──→ 다시 M365 · Azure 소비로
```

### 2.2 각 고리의 강도 검증

| 고리 | 데이터 | 강도 |
|---|---|---|
| M365 → Copilot | M365 Copilot 유료 좌석: FY26 2분기 약 1,500만 → 3분기 약 2,000만 → 4분기 **3,000만 이상**. 4분기 순증 좌석은 전 분기의 2배 이상(나델라, FY26 4분기 콜). M365 상업 좌석 4.5억 이상(FY26 2분기 기준) 대비 침투율은 **약 6.7%(추정)** | 강해지는 중. 다만 침투 초기 |
| Copilot → 매출 | 정가 월 30달러 기준 연환산 매출 상한은 약 108억 달러(**추정**, 할인 미반영)로 M365 Commercial 매출의 약 10.6%. 실제 할인 후 매출은 **데이터 부족**(미공시) | 아직 매출의 핵심 동력은 아니다 |
| 기업 데이터 → Azure | Commercial RPO(잔여이행의무) 6,780억 달러(+84%). 그러나 OpenAI 제외 시 증가율은 약 25%(Hood, FY26 4분기 콜 보도 인용) | **OpenAI를 빼면 플라이휠 속도가 크게 줄어든다** |
| OpenAI → Azure | FY26 OpenAI 관련 매출(수익배분 포함) **241억 달러**로 전사 매출의 7.3%. OpenAI 매출채권 60억 달러는 전체 매출채권의 7.4%(10-K Note, ASC 850 특수관계자 공시) | 크지만 한 고객에 집중돼 있다 |
| GitHub → 개발자 | GitHub Copilot 유료 구독자 470만, 전년 대비 +75%(2026년 1월 공시). 그러나 전문 개발자 사용 점유율은 Stack Overflow 기준 67%→51%로 하락. JetBrains 2026 조사에서는 Copilot 29%, Cursor 18%, Claude Code 18%(2차 블로그 인용, 원 보고서 미확인) | **약해지는 고리** |

### 2.3 OpenAI 관계: 자산인가 부채인가

**사실 (10-K FY2026)**
- 지분법 투자이며 전환 기준 지분율은 약 25%. 총 출자 약정 130억 달러 중 119억 달러를 납입했다.
- 2025년 10월 OpenAI 재편(PBC 전환)으로 지분 희석 이익이 생겼다. FY26 OpenAI 관련 순이익 효과는 +65억 달러(세후 +50억 달러). FY25에는 −48억 달러였다.
- 2026-04-27 계약 개정(복수 보도): Microsoft의 OpenAI IP 라이선스가 **비독점**이 됐다. OpenAI는 AWS·Google Cloud에서도 판매할 수 있다. AGI 조항은 삭제됐고 라이선스는 2032년까지 확정됐다. Microsoft가 OpenAI에 내던 재판매 수익배분은 없어졌다. OpenAI가 Microsoft에 내는 20% 수익배분은 2030년까지 유지되지만 상한이 생겼다(상한액 380억 달러 보도는 **미확인**).

**양면 검토**
- **자산 쪽**: 모델 IP 사용권이 2032년까지 확보됐고, 지분 약 25%를 갖고 있으며, FY26에 241억 달러의 매출을 냈다. Microsoft는 Anthropic에도 최대 50억 달러를 투자했다. Anthropic은 Azure 컴퓨팅 300억 달러를 약정했고, Claude는 GitHub Copilot·M365 Copilot·Foundry에 통합돼 있다(2025-11 발표). 즉 **"모델 중립 플랫폼"으로 위험을 분산하고 있다.**
- **부채 쪽**: 독점이 끝났으므로 "최고 모델은 Azure에서만"이라는 차별화가 사라졌다. Q2 FY26 기준 Commercial RPO의 약 45%가 OpenAI였다(Motley Fool 인용). FY26 말 비중은 미공시이고 약 32% 이상이라는 추정(Benzinga)만 있다. **적자를 내는 고객 하나에 백로그 3분의 1 이상이 걸려 있다**는 뜻이다(관점: OpenAI의 지불 능력은 외부 자금 조달에 달려 있다).

**결론 ★4**: M365 → Copilot 고리는 계정·데이터·보안이 이미 묶여 있어서 강하다.
**그러나 다른 한편으로**, Azure 쪽 플라이휠의 연료 상당 부분이 OpenAI 한 고객에서 나온다. 개발자 고리(GitHub)는 점유율이 내려가고 있다. 플라이휠의 중심은 "AI 모델"이 아니라 "기업 계정과 데이터"다. 이 구분이 투자 논지의 핵심이다(관점).

| **규모의 경제** | PP&E 순액 3,131억 달러(+52.7%), FY26에 데이터센터 88곳 가동(DCD). 세계 최대급 GPU 보유 | **규모가 곧 원가우위인지 검증되지 않았다.** Google은 자체 TPU를 갖고 있고, Google Cloud는 2026년 2분기 +82%, 백로그 5,140억 달러로 Azure(+43%)보다 빠르다. Microsoft 자체 칩(Maia)의 비중은 데이터 부족이다. Microsoft Cloud 매출총이익률은 71%→69%→66%로 3년 연속 하락했다 | ★4 |
| **기술 장벽** | OpenAI IP 사용권(2032년까지), 자체 MAI 모델, Anthropic 통합 | 모델 층은 범용화되고 있다(OpenAI 비독점, Claude는 3대 클라우드 모두에서 제공). 기술 자체보다 "유통"이 해자다 | ★3 |

**해자 종합 ★4**: 해자의 핵심은 기술이 아니라 **기업 업무 흐름(계정·데이터·보안·계약)에 들어가 있다는 것**이다. 전환비용 해자는 AI 시대에 오히려 강해질 수 있다. Copilot은 기업 데이터(Graph)가 있어야 쓸모가 있고, 그 데이터는 M365 안에 있기 때문이다.
**그러나 다른 한편으로**, Azure의 AI 인프라 사업은 해자가 아니라 **용량 경쟁**에 가깝다. 공급 제약이 풀리면 GPU 임대 가격이 원가 쪽으로 수렴할 위험이 있다(관점).

**"문을 닫으면 괴로운가" 테스트**

- 금융리스 부채 666억 달러(미래 지급총액 897억 달러). 현금 CapEx 1,159억 달러와 별개다.

### 6.2 해석: 두 가지 이야기가 모두 데이터와 맞는다

**A. "해자 강화" 논거 (데이터)**
1. 영업이익률은 4년 연속 올랐다(41.8%→46.8%). CapEx를 4배로 늘렸는데도 손익계산서 품질은 나빠지지 않았다.
2. 수요가 먼저다. RPO 6,780억 달러 중 12개월 내 인식분 약 2,034억 달러(추정, 30% 적용)는 FY26 매출의 61%다. 회사는 "수요가 용량을 넘는다"고 밝혔다.
3. AI가 M365 가격 인상의 명분이 됐다(E3 36→39달러, +8.3%. Copilot Chat과 보안 기능 번들). 즉 **AI 비용의 일부를 기존 해자 고객에게 전가할 수 있다.** 이는 가격결정력의 증거다.
4. 증분 영업이익률은 PBP 73.5%, IC 39.3%, 전사 53.3%다. 새 매출 1달러가 여전히 0.53달러의 영업이익을 낸다.

**B. "사업 품질 하락" 논거 (데이터)**
1. **이익과 현금이 갈라지고 있다.** FY24→FY26 조정 순이익은 +44.3%인데 FCF는 −9.6%다. 돤융핑이 말하는 "좋은 사업"은 결국 현금을 돌려주는 사업이다.
2. 손익계산서는 감가상각 시차로 좋아 보인다. 감가상각(385억 달러)은 CapEx(1,159억 달러)의 33.2%에 불과하다. 짧은 수명 자산이 3분의 2라면 앞으로 2~4년 동안 감가상각이 급증한다(추정). 내용연수 연장은 이 압력을 늦출 뿐 없애지 않는다.
3. 매출총이익률이 구조적으로 내려가고 있다. Microsoft Cloud 71%→66%, IC 62.2%→58.0%. 소프트웨어(한계비용이 거의 0)에서 인프라 임대(한계비용이 있음)로 매출 구성이 바뀌는 중이다.
4. 경쟁 구도: Google Cloud +82%(2026년 2분기, 백로그 5,140억 달러), AWS +37%. Azure +43%가 업계 최고가 아니다. 거액의 CapEx가 **상대적 우위를 만들지 못하고 "업계 입장권"이 되고 있다**는 해석이 가능하다(관점).
5. 고객 집중: OpenAI 매출 241억 달러는 Azure·서버 매출의 약 18.6%이고, Azure 매출(1,000억 달러 초과)의 최대 약 24%다(**추정**, 수익배분 포함이라 실제 Azure 비중은 더 낮다).

### 6.3 이 관점의 판정

**관점**: AI 투자는 **PBP(M365) 해자는 강화하고, IC(Azure)의 사업 성격은 "소프트웨어 플랫폼"에서 "고품질 유틸리티"로 바꾸고 있다.** 전사 사업 품질은 "★5 소프트웨어 프랜차이즈"에서 "★4 소프트웨어 프랜차이즈 + 자본집약 인프라 혼합체"로 바뀌는 중이다. 해자가 무너지는 것이 아니라 **해자를 지키는 비용이 올라가는 것**이다.

검증 가능한 반증 지표(이후 실적에서 볼 것):
- FCF/순이익이 0.5 아래로 계속 떨어지는지
- Microsoft Cloud 매출총이익률이 65% 아래로 내려가는지
- OpenAI 제외 RPO 증가율(현재 약 25%)
- Copilot 좌석 침투율이 10%를 넘는지
- FY27 1분기(오늘 장 마감 후) Azure 성장률이 가이던스 45%와 비교해 어떤지

## 7. 돤융핑의 "좋은 사업" 3요소 평가

### 7.1 차별화 ★4
- **사실**: 계정·생산성·보안·클라우드·개발도구·AI를 한 공급자, 한 계약으로 제공하는 회사는 Microsoft뿐이다. Google Workspace는 대기업 점유율이 낮고(정량 데이터 부족), AWS는 생산성 앱이 없다.
- **그러나**: 개별 층으로 보면 경쟁자가 같거나 더 낫다. 모델은 OpenAI·Anthropic·Google, 코딩 도구는 Cursor·Claude Code, AI 인프라 성장은 Google Cloud가 앞선다. 차별화의 원천은 "번들 + 유통"이다. 번들은 규제 위험(EU Teams 분리 사례)을 안고 있다.

### 7.2 가격결정력 ★5
| 증거 | 내용 | 출처 |
|---|---|---|
| M365 정가 인상 (2026-07-01) | M365 E3 36→39달러(+8.3%), E5 57→60달러. 상품군 전체로 5~43%(보도마다 수치가 다름: Heise는 O365 E3 23→25.25달러, E5 57→62달러로 보도. **불일치로 표기**) | Directions on Microsoft, Heise |
| 상위 번들 | M365 E7(월 99달러) = E5 + Copilot + Agent 365(단독 15달러) + Entra Suite. 개별 구매 합계는 117달러 | Redress Compliance, Red River(3자 분석) |
| Copilot 별도 과금 | 좌석당 월 30달러 수준. 정가 인상 대상에서 제외돼 별도로 판매 | 복수 보도 |
| 소비자 | M365 Consumer +23.9%(FY26). 가격 인상 + Copilot 번들 | 10-K |
| 인상 후 반응 | 2026-07 인상 후 첫 분기 실적(FY27 1분기)은 **미발표**. 인상 효과는 "다음 갱신 시점"부터 적용돼 수년에 걸쳐 나타난다 | |

**판정**: 기업 고객에게 정가를 올리면서 기능을 묶어 넣는 방식은 전환비용 해자가 실재한다는 가장 직접적인 증거다.
**그러나 다른 한편으로**, Copilot의 실제 할인 후 가격과 갱신율은 공시되지 않는다. 좌석 3,000만 개 중 무료·번들 할인 비중은 **데이터 부족**이다. "AI 가격결정력"과 "기존 M365 가격결정력"은 구분해야 한다. 증명된 것은 후자다.

### 7.3 지속 가능한 경쟁 우위 ★4
- PBP: 영업이익률이 57.8%에서 59.9%로 오르며 우위가 넓어지고 있다. ★5
- IC: 영업이익률 41%대는 유지되지만 매출총이익률이 하락하고, 경쟁자가 더 빨리 성장하며, 고객이 OpenAI에 집중돼 있다. ★3
- MPC: 정체. ★2
- 이익 비중으로 가중하면 ★4다.

## 8. 경영진의 제품 직관 (언어 검증)

- 나델라 FY26 4분기 발언: "cost-to-outcome curve의 최전선을 밀고 있다", "모든 고객이 토큰을 비즈니스 결과로 바꾸게 한다"(8-K). 의미는 구체적이다. 단가당 성과(토큰 원가)를 핵심 지표로 본다는 뜻이고, 인프라 사업자다운 언어다.
- 10-K는 "우리의 미래 성장은 현재 제품 범주의 정의, 비즈니스 모델, 영업 방식을 넘어서는 능력에 달려 있다"고 쓴다. 스스로 사업 모델 전환을 인정한 것이다.
- **관점**: 경영진 언어는 관료적이지 않고 제품과 원가 중심이다. 그러나 메시지의 중심이 "좌석·사용자"에서 "토큰·용량"으로 옮겨 간 것 자체가 사업 성격 변화의 신호다. 경영진 평가의 상세는 리루 관점 보고서에 맡긴다.

| 가장 과소평가된 위험(비컨센서스) | ① OpenAI 비독점 전환 후에도 백로그의 3분의 1 이상이 OpenAI라는 **비대칭**(이익은 공유하고 위험은 집중). ② 감가상각 시차와 내용연수 연장으로 **손익계산서가 현금흐름보다 2~3년 늦게 진실을 반영**한다. ③ Google Cloud의 성장 속도(+82%)는 "규모의 경제가 Microsoft만의 것이 아니다"라는 데이터다 |
| 가장 과소평가된 강점(비컨센서스) | Copilot 침투율이 약 6.7%에 불과하다. 시장이 AI의 승패를 Azure 성장률로만 보는 동안, 진짜 해자 수익화(M365 ARPU)는 이제 시작 단계다. 이 부분은 자본이 거의 들지 않는다 |
| 가격 | 시가총액 3.95조 달러(검산 0.22% ✅), PER 29.7배(OpenAI 이익 제외 조정 EPS 17.28달러 기준 30.7배), **FCF 수익률 1.69%.** 좋은 사업이지만 "싼 가격"은 아니다. 상세 밸류에이션은 버핏 관점 보고서에 맡긴다 |

**종합 사업 품질 ★4**: 좋은 사업이 맞지만, 4년 전보다 "더 좋은 사업"이 된 것은 아니다. **더 큰 사업이 됐고, 더 비싼 사업이 됐다.**
