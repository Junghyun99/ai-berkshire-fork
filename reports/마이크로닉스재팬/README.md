**한 줄 판단**: HBM 프로브카드 병목은 진짜이고 순현금 136억 엔으로 재무는 탄탄하다. 그러나 현재가는 정점권 이익(2Q 영업이익률 35.1%, 회사 스스로 3Q 27.4%로 가이드)을 지속 이익으로 가정한 가격이라 정상이익 기준 내재가치보다 40~71% 비싸다. 매출 49.9%인 삼성에 한국 경쟁사 진입 보도가 있고 2026년부터 수주 공시가 중단돼 점유율 변화를 확인할 수 없다.

**실행 계획**: 비중 상한 4%, 분할 매수 6,300엔 1.5%(3분기 결산 확인 후) / 5,500엔 1% / 4,800엔 1%(capex 삭감 미확인 시), 8,110엔 이상 신규 매수 금지. 현재 대기.

**다음 확인**: 2026-11-12 3분기 결산 — 영업이익률·통기 가이던스·수주 언급·삼성 HBM4E 공급.
