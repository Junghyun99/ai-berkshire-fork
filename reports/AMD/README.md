# AMD (AMD) — 투자 리서치 팀

> `/investment-team AMD` 산출물. 작성일 2026-11-20. 기준가 489.19 USD(2026-11-19 종가).

## 핵심 결론

**판단: 관망 · 확신도 ★★ · 내재가치 400~480 USD**

- 사업은 좋아지고 있다.
  - Q3'26 데이터센터 매출 8.55B USD(+97%), 부문 영업이익률 24.7% → 33.7%.
  - Q4'26 가이던스 매출 약 17B USD(+65.5%).
  - 순현금 8.7B USD, 서버 CPU 매출 점유율 46.2%(Mercury, 2차 보도).
- 그러나 가격과 자본 구조가 사업보다 앞서 있다.
  - 현재가는 확률가중 가치 436.68 USD보다 약 12% 높고, 내재가치 범위 상단 480 USD도 넘는다. FCF 수익률은 0.87%다.
  - 고객 워런트로 최대 19.5% 희석될 수 있고, 생태계 지원 약정은 34.1B USD(자기자본의 49.8%)다.
  - Q3'26 영업CF/순이익은 0.50, 재고는 +45%다(한 분기 신호, Q4'26에서 판별).
- 매수는 분명히 기각되고, 회피와는 근소하게 갈린다. 그래서 회피 쪽으로 기운 관망 ★2다.
- 실행 계획은 비중 상한 2.5%다.
  - 분할 매수: 400 USD 0.75% → 330 USD 0.75% → 286 USD 1%.
  - 1차는 Q4'26 영업CF/순이익 1.0 이상 확인 후 실행한다(실적 발표 전 도달 시 절반).
  - 신규 매수 금지선은 480 USD 이상이다. 현재가는 금지 구간이어서 대기 상태다.
- 반증 조건
  - 회피 쪽: Q4'26 영업CF/순이익 1.0 미만이면서 재고 11.46B 이상 유지, 또는 생태계 지원 약정 34.1B에서 추가 증가.
  - 매수 쪽: 주가 400 USD 이하이면서 Q4'26 영업CF/순이익 1.0 이상, 또는 DC 매출 성장률이 NVIDIA DC 성장률을 2분기 연속 상회.

- AMD는 Instinct GPU 단독 매출·마진을 공시하지 않는다. 가치의 핵심 부분이 자료량과 무관하게 불확실하다.
- Mercury Research 점유율은 2차 보도 기준이다. 경쟁사 비교는 분기 종료일이 다르다.
