- 그러나 가격에 안전마진이 없고, 해자의 땅은 남의 것이다.
  - 오너어닝스 DCF 중심 294 USD 대비 안전마진 −21%. 현재가는 5년 연 18~20% 오너어닝스 성장을 요구한다.
  - AXON의 연료(타사 앱 SDK 신호)는 회사 소유가 아니며, 아동 데이터 소송(샌디에이고·네덜란드)이 진행 중이고 충당금은 0.

- 토론 판정은 약세 우세(가격) → 관망. 강세 측도 현재가의 안전마진 부재를 인정했으나, 영구 손실 경로는 "검증 불가"이지 "발생 확인"이 아니라 회피는 아님. 확신도 ★3.
