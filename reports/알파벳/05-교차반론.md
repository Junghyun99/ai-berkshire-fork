# 알파벳 교차 반론 라운드 (1라운드)

> 작성일 2026-11-04 · team-lead 정리 · 4개 관점 Agent가 다른 세 관점의 요약(판단 + 핵심 주장 3개)을 받아 600자 안에서 반박·인정·최종 판단을 회신했다. 원 보고서(01~04)는 수정하지 않았다.
> **네 관점이 모두 '관망'이어서 반대 판단을 낸 관점이 없었다.** 그래서 각 Agent에 "자기 논거의 가장 약한 고리를 스스로 공격하라"고 지시하고, 두 방향을 데이터로 시험하게 했다: (a) 버핏 중앙 255$·리루 확률가중 261$가 현재가 280.03$보다 낮은데 왜 '회피'가 아닌가, (b) Cloud +103%·검색 점유율 89.9%·역DCF 10.4%를 보면 왜 '매수'가 아닌가.

## 1. 돤융핑 관점 (business-analyst)

**반박**
- **가장 약한 고리(자기 정정)**: 원 보고서 7장의 "광고 영업이익 TTM 약 1,594억$로 시총 3,433억$를 감당"은 **단위 오류**다. 팩트시트 시총은 3,432.87B$ = 3조 4,329억$이고, 광고 영업이익의 약 21.5배라 "감당"이라는 근거는 성립하지 않는다. 유료 클릭 +8%도 2차 출처다.
- (a) 회피: 현재가 280.03$는 버핏 범위 215~290$ 안이고 사업 훼손은 없다(Services 이익률 40.7%, 8-K). 안전마진 부재의 근거로는 충분하지만 회피 근거는 아니다 — 회피는 2027 CapEx 3,000억$ 초과와 연간 FCF 마이너스가 확정돼야 한다.
- (b) 매수: 역DCF는 주당 오너 이익 연 10.4% 성장을 전제하는데 출발점 FCF−SBC가 -107억$, 자사주 0. Cloud +103%의 수주잔고는 Anthropic·Crux AI에 집중.

**인정**: 멍거 — Search +12% < 시장 +14.2%(WARC), 점유율 89.9%만으로 지갑 점유 손실을 가릴 수 없다 → 플라이휠 ★3 하방. 버핏 — 감가상각으로 영업이익률 약 27%까지 하락 가능하면 "Cloud 과대 표시"보다 더 강한 압박. 7장 시총 문장 철회.

**최종**: **관점 판단**: 관망 — 검색 해자는 건재하나 수익화가 시장보다 느리게 늘고 오너 이익이 마이너스라 매수 근거가 없고, 사업 훼손이 확정되지 않아 회피도 이르다.

## 2. 버핏 관점 (financial-analyst)

**반박**
- **가장 약한 고리**: 오너 이익 DCF(중립 272$)는 성장 CapEx 약 118B가 자본비용 이상을 번다고 전제한다. 이 전제를 빼면 무성장 가치는 114$에 그친다.
- (a) 회피: 현재가 280.03$는 중앙 255$보다 9.8% 높지만 범위 215~290$ 안. 정상 ROIC 36%, 지분 제외 순현금 25.9B. 회피 근거인 영구손실 요건(가치 훼손)은 데이터로 확인되지 않는다.
- (b) 매수: 역DCF 10.4%는 이미 가격에 들어간 성장이지 할인이 아니다. FCF−SBC −10.7B, Search +12.0%는 Cloud와 별개로 둔화 중(8-K).

**인정**: 돤융핑 — 공유 AI 비용 −4.47B→−7.66B(+71%, 8-K)로 Cloud 이익률 36.2%는 과대 표시, 수주잔고에 특수관계자 Crux AI 16.8B(10-Q). 수정 — SOTP에서 Cloud에 연율 NOPAT 28배는 과하다 → 20배로 내리면 주당 약 20$ 감소 → **내재가치 210~275$, 중앙 245$, 25% 안전마진 매수가 약 184$**(추정).

**최종**: **관점 판단**: 관망 — 현재가가 하향한 범위의 상단 부근으로 안전마진은 없지만, 정상 ROIC 36%·순현금 상태에서 영구손실 근거가 아직 확인되지 않아 회피도 아니다.

## 3. 멍거 관점 (industry-researcher)

**반박**
- **가장 약한 고리**: "시장이 Cloud를 과소평가"라고 썼으나 AI 모델 개발비는 Alphabet-level에 잡히고 그 손실이 44.7억→76.6억$(+71%, 8-K) — Cloud 이익률 36.2%는 실제보다 좋아 보인다.
- (a) 회피: 버핏 중앙 255$는 현재가보다 9.8% 낮지만 현재가는 범위 안, 리루 261$는 추정. 회피 쪽 반증 조건 미발생(Search +12% 두 자릿수, 2027 CapEx 수치 가이던스 없음).
- (b) 매수: 정상 PER 26.9배, FCF−SBC -107억$, 1~9월 CapEx/영업CF 103.8%인데 역DCF는 주당 오너 이익 연 10.4% 성장을 요구 — 마이너스 출발점에서 이 성장을 요구하는 가격.

**인정**: Cloud 과대 표시와 수주잔고의 Anthropic(최소 약 1,145억$, 2차) 집중 → Cloud ★4→★3, "Cloud 과소평가" 철회. Search Q2→Q3 +0.1%(전년 +4.4%) → Search 악화 '완만'→'뚜렷'. 기울기를 회피 쪽으로 이동 — 2027-02 CapEx 가이던스 3,000억$ 초과 + 연간 FCF 마이너스 확정 시 회피.

**최종**: **관점 판단**: 관망 — 경쟁 지위는 유지되지만 Cloud 성과는 실제보다 좋아 보이고 Search 감속은 뚜렷하며, 현재가는 가치 범위의 상단이고 회피 쪽 반증 조건은 아직 발생하지 않았다.

## 4. 리루 관점 (risk-assessor)

**반박**
- **가장 약한 고리**: 확률가중 가치 261$는 확률 25/50/25 가정에 크게 기댄다. 낙관 30%·비관 20%로 바꾸면 약 275$로 현재가와 거의 같아진다(financial_rigor 산출값으로 계산).
- (a) 회피: 261$는 현재가보다 7% 낮지만 가정 오차 안이고, 영구 손실의 근거(2027 CapEx 3,000억$ 초과 확정)가 아직 없다.
- (b) 매수: 역DCF 출발점 FCF−SBC -107억$, Cloud +103%는 Alphabet-level 손실 +71%(76.6억$)와 함께 봐야 하고, Search +12% < 시장 +14.2%(WARC).

**인정**: 돤융핑 — Cloud 이익률은 AI 개발비가 빠져서 부풀려 보인다 → 피차이 운영 능력 ★5→★4. 멍거 — Search가 시장보다 느린 것은 FX 탓만으로 돌릴 수 없다 → "한 분기로 단정할 수 없다"는 유보를 약화.

**최종**: **관점 판단**: 관망 — 버핏 255$와 리루 261$라는 두 추정은 서로 독립적으로 냈지만 둘 다 현재가보다 낮고 그 차이가 오차 범위 안에 있으며, 2027-02 CapEx 가이던스라는 확정 트리거가 3개월 안에 와서 회피도 매수도 아닌 관망을 유지한다.

## 5. team-lead 정리: 반론으로 바뀐 것

1. **판단이 바뀐 관점**: 없음(4개 관점 모두 관망). 그러나 **네 관점 모두 하방으로 수정**했다 — 버핏 내재가치 하향(중앙 255→245$), 멍거·리루·버핏이 Cloud 이익률 과대 표시를 인정, 멍거 Cloud ★4→★3·Search 악화 '뚜렷', 리루 피차이 ★5→★4.
2. **정정 사항(오류)**: 01 돤융핑 보고서 7장 "광고 영업이익 약 1,594억$로 시총 3,433억$를 감당"은 단위 오류다. 실제 시총은 3조 4,329억$(팩트시트 3,432.87B$)로 광고 영업이익의 약 21.5배다. 원 보고서는 교차 반론 규칙상 고치지 않았고, 이 정정을 최종보고서에 반영한다.
3. **네 관점이 합의한 사실**
   - 정상 PER 약 26~27배(GAAP 14.6배는 TTM 지분증권 평가이익 129.6B 착시), 코어 EV/EBIT 20.3배.
   - FCF−SBC −10.7B, 2026 1~9월 CapEx/영업CF 103.8%, 자사주 매입 0.
   - Cloud 이익률 36.2%는 Alphabet-level로 빠진 AI 개발비(손실 +71%) 때문에 과대 표시.
   - Search 성장 +12%는 검색광고 시장(+14.2%, WARC)보다 느리고, Q2→Q3 +0.1%.
   - 회피 쪽 반증 조건은 아직 미발생 — 분기점은 2027-02 무렵 Q4 실적·2027 CapEx 가이던스.
4. **(a) 회피 시험 결과**: 현재가 280.03$는 버핏 수정 범위 상단(275$)을 약 2% 넘고 중앙(245$) 대비 +14%다. 그러나 네 관점 모두 "가치 훼손(영구손실) 근거가 데이터로 확인되지 않았다"며 회피를 기각했다 — ROIC 36%·지분 제외 순현금 25.9B·Services 이익률 40.7%. 가치 추정의 오차(리루: 확률 조정만으로 261→275$)가 고평가 폭과 비슷하다.
5. **(b) 매수 시험 결과**: 역DCF 10.4%는 할인이 아니라 이미 가격에 들어간 성장이고 출발점(오너 이익)이 마이너스 — 네 관점 모두 기각.
6. **반박되지 않고 남은 가장 강한 반대 논거**: 매수 쪽 — Cloud +103%·점유율 15% 사상 최고와 검색 점유율 89.9%는 사실이고, 이 투자가 자본비용 이상을 벌면 DCF 중립 272$ 이상이 정당화된다. 회피 쪽 — 성장 CapEx가 자본비용을 못 벌면 무성장 가치는 114$(버핏)이고, 인프라 붐의 역사적 기저율(멍거)은 투자자 손실 쪽이다. 둘 다 2027 CapEx 가이던스와 FCF 회복 여부로 판가름난다.
7. **과거 판단(체크리스트 관망 ★3, 220~290$)과의 차이**: 판단 방향 동일. 내재가치는 220~290$에서 210~275$로 소폭 하향(Cloud 멀티플 조정·감가상각 시차·자사주 중단 반영).
8. **이해상충 고지**: 이 분석을 작성한 모델(Claude)은 Anthropic이 만들었다. Anthropic은 알파벳의 투자 대상이자 Google Cloud의 대형 고객이다. Anthropic 관련 서술은 공시·보도 수치만 썼고, Anthropic 수주잔고 비중은 출처 간 불일치로 결론의 근거로 쓰지 않았다(04).
