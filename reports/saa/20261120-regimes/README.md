# 자산배분 방법론 잠정 결론과 시장 상황별 진단

## 결론

현재 연구는 최종 배분안 확정 전, 자산배분 기법의 효과와 한계를 비교하는 단계다. 다섯 전략의 전체 평가와 시장 상황별 진단을 종합하면 동일가중은 비교 기준으로 유지할 근거가 있고, 위험균형은 낙폭 완화 후보로 남길 근거가 있다. **낙폭이 작다는 이유만으로 위험조정 수익률도 우수하다고 판단하면 안 된다.**

PR #96의 공식 분배락일 종가 재투자 입력에서, 위험균형은 동일가중보다 주식 하락 달의 평균 손실이 작고 상승 달의 평균 수익도 작았다. 36개월 이동 구간 82개 모두에서 월말 MDD가 작았지만 CAGR은 한 번도 높지 않았고 Sharpe·Sortino는 각각 5개 구간에서만 높았다. 따라서 동일가중을 위험균형으로 일괄 교체하거나 시장 상황별 자동 전환 규칙을 채택할 근거는 부족하다.

이는 이미 관측한 표본에 대한 사후 진단이다. 투자 가능한 예측 신호나 새로운 미사용 구간 검증 결과가 아니다.

## 방법론의 진행 위치

| 단계 | 연구 내용 | 현재 판정 |
| --- | --- | --- |
| Phase 0 | 연구·제안·검증·승인 역할 분리 | 기본 설계 정리 |
| Phase 1 | 투자정책 작성·평가·승인·개정 | 기본 구현·검증 수행, 실제 IPS DRAFT |
| Phase 2-1 | SAA 기법·비교 기준 | 1차 방법론 정리 |
| Phase 2-2 | 총수익·환율·금리 계약과 자료 | 실제 입력 확보·부분 대조, 원천·빈티지 미결 |
| Phase 2-3 | 실제 자료 기반 기법 비교 | 잠정 결론 및 이번 시장 상황별 진단 |
| 후속 연구 | 채택·보류 기준, 향후 평가 | 최종 전략·정책 미확정 |

계좌관리·브로커 연결은 현재 연구 범위가 아니다. 기업·시장 연구를 배분 변경 판단에 연결하는 방법론도 아직 충분히 구현·검증되지 않았다.

## 자료와 분석 설계

선행 [총수익률 재구성·전략 민감도](../20261120-tr-rebuild/README.md)의 세 실행 결과를 모두 분석했다. 원래 기준선, 공식 분배 역방향 모델, 공식 분배락일 종가 재투자다. 아래 표는 마지막 입력을 사용한다.

- 한국 주식·S&P500·NASDAQ100·한국 국채·미국 국채의 5자산.
- 평가 2017-01~2026-09, 117개월. 기존 60개월 학습, 신호 공백 2개월, 12개월 리밸런싱, 비용 10bp, 초기매수비용 제외를 유지했다.
- 전략을 새로 조정하거나 재최적화하지 않았다. 선행 실험의 실제 전략 수익경로를 분석한다.
- 주식 바스켓: 한국 주식·S&P500·NASDAQ100의 해당 월 KRW 수익률 단순평균.
- 채권 바스켓: 한국·미국 국채의 해당 월 KRW 수익률 단순평균.
- 각 평균이 0 이상이면 상승, 음수면 하락으로 분류한다. 이는 세계 시장 전체나 경기·금리 국면의 정의가 아니다. 미국 자산의 KRW 환율 효과와 주식 지수 중복 노출도 포함된다.
- 월말에야 알 수 있는 당월 수익률로 분류하므로 미래 투자 판단에 직접 사용할 수 없다.
- 분리된 월들을 이어 붙여 CAGR·MDD를 계산하지 않았다. 상황별 표에는 비용 반영 월별 수익률의 산술평균만 사용한다.
- 연속 36개월 구간은 2017-01~2019-12부터 2023-10~2026-09까지 82개다. 원래 거래경로와 비용을 잘라 계산하고 각 창에서 자산가치 1로 시작한다. 새 전략 시작·재학습·초기매수를 가정하지 않는다.

## 시장 상황별 평균 월수익률

단위 %. 각 행은 해당 조건에 속한 월의 평균이며 연환산 수익률이 아니다.

| 사후 분류 | 개월 | 동일가중 | 최소분산 | shrinkage 최소분산 | 최대 Sharpe | 위험균형 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 주식 상승·채권 상승 | 44 | 3.1906 | 1.4385 | 1.7619 | 3.1956 | 2.2307 |
| 주식 상승·채권 하락 | 37 | 2.0561 | -0.1456 | 0.0799 | 1.3061 | 0.7745 |
| 주식 하락·채권 상승 | 16 | -1.8067 | -0.2350 | -0.2504 | -1.4526 | -0.7474 |
| 주식 하락·채권 하락 | 20 | -2.9327 | -1.5289 | -1.6132 | -3.1859 | -2.0894 |

위험균형은 주식 하락·채권 상승에서 동일가중 대비 월평균 약 +1.0593%p, 동반 하락에서 +0.8433%p였다. 반대로 주식 상승·채권 하락에서 약 -1.2817%p, 동반 상승에서 -0.9599%p였다. 이 표는 방어와 상승 참여의 상충관계를 보여준다.

최대 Sharpe 전략은 동반 하락 달에 동일가중보다 평균 손실이 컸다. 과거 추정치로 Sharpe를 최대화하도록 설계해도 미래 구간의 방어가 자동 보장되지는 않았다는 관측이다. 최소분산 계열의 낮은 손실 역시 동일한 주식 노출에서의 우월성을 입증하지 않는다. 자산 비중·변동성·노출이 달라 인과적 기법 효과와 분리되지 않았기 때문이다.

## 36개월 이동 평가

동일가중보다 엄격하게 높은 지표를 기록한 창 수. MDD는 음수 값이므로 높은 값이 더 작은 낙폭이다. 분모는 모두 82개다.

| 전략 | CAGR 우위 | MDD 우위 | Sharpe 우위 | Sortino 우위 | MDD·Sharpe·Sortino 동시 우위 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 최소분산 | 0 | 73 | 0 | 0 | 0 |
| shrinkage 최소분산 | 0 | 77 | 17 | 16 | 16 |
| 최대 Sharpe | 15 | 7 | 14 | 13 | 4 |
| 위험균형 | 0 | 82 | 5 | 5 | 4 |

세 가지 입력에서 위 승수는 모두 같았다. 창들은 35개월씩 겹치므로 82개의 독립 표본이 아니며, 이 비율을 미래 승률·통계적 유의성으로 해석하지 않는다. 이번에 선택한 36개월 진단 자체도 사후 탐색이다. 전체 구간의 순위가 모든 하위 구간에 동일하다는 주장도 하지 않는다.

## 잠정 판단과 다음 연구

| 방법 | 현재 역할 | 채택을 위해 더 필요한 근거 |
| --- | --- | --- |
| 동일가중 | 단순 비교 기준선 유지 | 다양한 표본·노출 조건에서 비교, 미래 성과 미확정 |
| 위험균형 | 낙폭 완화 후보 | 수익 희생과 위험 완화의 교환을 평가하고 위험조정 수익 개선을 별도 확인 |
| 최소분산·shrinkage | 방어 강도를 비교하는 후보 | 낮은 주식 노출의 효과와 배분 기법 효과 분리 |
| 최대 Sharpe | 추정오차·집중도 민감성 연구 후보 | 기간·후보 탐색·비용·비중 안정성 검증, 과거 최적값 의존 경계 |

지금 확정할 것은 연구 역할이며 최종 투자 비중이 아니다. 기존 사용자 승인 평가 기준을 새 수치로 변경하지 않는다. IPS v0.4는 DRAFT다.

다음 핵심 연구는 **동일한 위험 또는 주식 노출에서의 비교 설계**다. 원래 위험균형과 동일가중을 그대로 비교하면 방어 성과가 단순한 주식 비중 축소 때문인지 구분하기 어렵다. 고정 주식 노출 비교와 학습구간만으로 정하는 변동성 목표 비교를 각각 설계하고, 비용·현금 수익·추가 가정을 명시해야 한다. 전체 평가 구간의 실현 변동성을 보고 비중을 맞추면 미래 정보가 섞이므로 금지한다.

시장 전환 전략을 바로 만들기보다는 어떤 신호를 언제 관측할 수 있는지, 분류 정확도와 전환 비용을 포함해 기존 고정 방식보다 나은지를 별도 가설로 정해야 한다. 이번 사후 분류를 그대로 매매 규칙으로 변환하지 않는다.

한국 국채 공식 장기 TR, 독립 종가, 과거 가용시점·빈티지는 계속 미결이다. research_proxy와 source gate를 유지한다.

## 재현과 검증

먼저 선행 PR #96의 rebuild.py, compare_strategies.py로 rebuilt-results.json과 full.json을 생성한다. 동일 엔진 해시는 선행 strategy-summary.json을 따른다.

```bash
python3 reports/saa/20261120-regimes/analyze.py --korea /path/to/korea-unpacked --rebuilt /path/to/rebuilt-results.json --comparison /path/to/full.json --tools-dir tools --output /path/to/regime-results.json
python3 -m unittest discover -s reports/saa/20261120-regimes -p test_analyze.py -v
python3 tools/report_audit.py extract --report reports/saa/20261120-regimes/README.md --dry-run
```

실제 실행 exit 0, 합성 회귀 3개 통과. 상황 4개 분할·0 경계, 비용의 단일 복리 적용, 길이 불일치 차단을 검증한다. 기존 전체 테스트와 독립 원천 검증은 반복하지 않았다. report_audit dry-run은 표본 추출이며 독립 인증이 아니다. 입력 JSON의 해시는 results.json에 기록했다. 재실행일 메타데이터가 바뀌면 rebuilt JSON 바이트 해시도 달라질 수 있으므로 선행 원본 해시와 수치 내용을 함께 대조한다.
