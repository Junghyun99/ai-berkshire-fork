## 1. 확인한 표본과 새로운 평가 구간의 경계

기존 입력 종료는 2026-09, 한국 포함 공통 입력은 2011-11~2026-09(179개월), 주요 OOS는 2017-01~2026-09(117개월)이다. 이 OOS는 모델 학습에서는 분리했지만 전략·조건을 반복 비교한 **탐색 표본**이다. 이제 같은 과거를 잘라 “미사용”이라 부르지 않는다. FRED 원본 일부에 2026-10 관측도 포함되어 있으므로 2026-10을 미사용으로 주장하지 않는다. 2026-11은 이미 진행 중인 달이므로 새 평가의 첫 완전한 달로 삼지 않는다.

미래 계획의 최초 후보는 **2026-12**다. 실제 시작은 아래 동결 조건을 모두 충족한 시점 이후의 첫 완전한 달로 정하며, 2026-12보다 앞설 수 없다. 11월 내 준비가 끝나지 않으면 다음 완전한 달로 이동한다. 이 날짜는 제안이며 아직 예약·자동 수집·동결하지 않았다. 다른 프로젝트에서 이미 해당 구간 결과를 확인했으면 노출 기록을 남기고 새 구간을 정한다.

5자산은 KR_EQUITY, US_SP500, US_NASDAQ100, KR_TREASURY10Y, US_TREASURY7_10Y다. 기존 60/40·30/30/20/20은 연구용 설정이다. 국내상장 해외 ETF는 경제적 노출 기준을 유지하고 SPY/NASDAQ 중복을 공개한다. 한국 국채가 미검증이라고 조용히 제거하여 더 높은 주식비중의 결과로 대체하지 않는다. 별도 미국 부분집합 실험은 별도 계획 ID가 필요하다.

과거 재현 조건: KRW, 학습60개월, 신호 공백2개월, 리밸런싱12개월, 비용10bp, 최초 매수비용 제외. 후보 그리드는 seed17, 무작위2500개와 결정적 후보를 합친 근사 탐색이며 shrinkage는 50% 대각 휴리스틱이다. 이 값들은 이미 사용한 조건의 기록이다.

미래 프로토콜 후보도 동일값으로 시작하되, **확인된 가용시점 검사를 각 학습 컷오프에 적용**하고 최초 진입 비용도 포함하는 안을 제시한다. 따라서 과거 성과와 비용 기준이 다를 수 있어 별도 버전으로 기록한다. 현재 엔진의 최초 비용 처리와 가용시점 연결은 구현/테스트를 마쳐야 동결할 수 있다. 비용 0/30bp, 주기3/6개월은 사전 등록한 보조 민감도이며 유리한 결과만 주 결과로 교체하지 않는다.

`turnover=sum(abs(target-drifted))`에 적용하는 거래금액 단위 비용이다. 현재 결과 키의 round_trip 명칭만으로 매수·매도에 비용을 이중 적용하지 않는다. 세금·체결충격·계좌별 비용은 미반영이며 Phase 2-4 이후 별도 조건으로 비교한다. USD는 동일 경로의 보조 환산 결과로 제공하되 환헤지 성과로 부르지 않는다.

## 3. 지표 정의와 판정 후보

월 순수익 r, 월 RF f, e=r-f, N=월 수, V0=1, Vt=직전V×(1+r)로 정의한다. 현재 엔진과 맞추어 아래를 기록한다.

| 지표 | 정의 | 해석·주의 |
| --- | --- | --- |
| CAGR | V_N^(12/N)-1 | 산술평균×12나 미래 기대수익과 다름 |
| 월말 MDD | min(V_t / max(V_0..V_t)-1) | 초기자산1 포함. 일중/일별 최대낙폭 아님 |
| Sharpe RF | mean(e)/sample_std(e)×sqrt(12) | 현재 구현은 초과수익의 표준편차. 시계열 의존성·연환산 가정 별도 표시 |
| Sortino RF | mean(e)/sqrt(mean(min(e,0)^2))×sqrt(12) | 전체 N으로 하방제곱 평균, 손실월 수만으로 나누지 않음 |
| RF0/MAR0 | f=0인 위 정의 | 기존 보조 지표. 낮은/높은 값이 나오는 기준을 사후 선택하지 않음 |
| 일별 MDD | 일별 순자산으로 같은 peak 식 | 현재 월간 엔진에서 산출 불가. 월간 수익을 보간해 만들지 않음 |
| 회전율/비용 | 동일 계산 경로의 거래합·비용 | 성과 개선과 구현 부담을 함께 평가 |

분모가 0이면 지표는 미정(null)이며 무한대로 순위를 매기지 않는다. 납입/인출이 들어오는 실제 계좌에서는 TWR/MWR가 별도로 필요하다.

선택 후보 A: **Sharpe를 주지표, Sortino와 MDD를 보조 제약**으로 사용. 후보 B: **Sortino를 주지표, Sharpe와 MDD를 보조 제약**으로 사용. 어느 쪽도 아직 승인되지 않았다. RF 후보는 통화·기간이 맞는 검증된 현금성 TR 또는 금리에서 변환한 명시적 추정 프록시다. 현재 한국 은행간 금리/1200·관측3개월 지연은 연구 가정이지 최종 무위험 기준이 아니다. MAR 후보는 월 RF 또는 사용자가 정한 요구수익이며 별도 구현과 선택이 필요하다.

최종 성공 조건은 주지표 개선과 허용 열화 폭(월말 MDD·보조 지표), 비교 기준선을 함께 동결해야 한다. 개선 최소폭·허용 열화 숫자는 현재 null이다. 과거 결과에 맞는 문턱을 만들어 승인된 것으로 표시하지 않는다. 확증 판정을 원하면 1개 주 후보와 1개 기준선·주지표를 먼저 선택한다. 여러 후보를 확증 비교할 경우 family 정의와 다중비교 보정·구간 산출법을 사전에 추가해야 한다. 현재 부트스트랩 코드는 이 보정을 구현하지 않았다.

## 4. CMA: 과거 평균과 미래 가정 분리

[CFA Part I](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/capital-market-expectations-part-i)는 기대치의 자산 간·기간 간 일관성을 강조한다. [Part II](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/capital-market-expectations-part-ii)는 표본 평균의 추정 오차와 통계·현금흐름·위험 프리미엄 접근을 설명한다. 이 자료는 아래 작성 틀의 근거이며 특정 기대수익 숫자의 근거가 아니다.

| 자산 | 작성할 가정·범위 | 필요한 근거 | 현재 수치 |
| --- | --- | --- | --- |
| 주식 | 배당/이익성장/평가배수 변화의 하방·기준·상방 | 기준일 가격·기업이익·분배 및 기간별 가정 | null, 미추정 |
| 국채 | 시작수익률·금리경로·듀레이션/롤다운·재투자·비용 | 원곡선·바스켓/만기·현금흐름·금리 시나리오 | null, 미추정 |
| 현금성 | 단기금리 경로·월 수익 변환·비용 | 실제 접근 가능한 지표/상품과 공표시각 | null, 미추정 |
| 환율 | 무변화·강세·약세 시나리오와 헤지비용 | 기준일 FX·금리차·모형/근거 | null, 미추정 |
| 공분산 | 표본/축소 추정의 불확실성과 국면 민감도 | 같은 통화·기간·가용성의 데이터 | 과거 기술통계만 있음 |

전망 기간은 사용자 투자기간10~20년과 단기 평가기간을 구분한다. CMA 각 수치에는 단위·명목/실질·세전/세후·통화·기준일·근거·불확실성·작성자를 붙인다. 수치 범위가 없으므로 이번에 CMA가 완성됐다고 하지 않는다. 역사적 max_sharpe의 표본평균을 CMA로 이름만 바꾸지 않는다.

## 5. 동결·실행·변경 관리

계획 상태는 DRAFT → READY_FOR_FREEZE → FROZEN → RUNNING → EVALUATED 또는 INVALIDATED로 관리하는 **설계**다. 실행 오케스트레이터는 아직 없다. JSON은 실행 명령이 아니라 검토용 계약이다.

동결 전 필수:

1. #56에서 주지표·RF/MAR·주 비교군·허용 열화 폭을 명시적으로 선택한다.
2. #53/#54의 사용 자료 범위·한계 승인, 가용시점 증거·엔진 연결 및 최초 비용 테스트를 완료한다. 미인증 자료로 계속하면 확증이 아닌 전향적 프록시 연구로 명확히 재분류한다.
3. 리밸런싱 시각/가격 기준·공표 컷오프·기간·수수료·예외/결측 처리·초기 NAV와 모든 전략 설정을 정한다.
4. 계획/코드 커밋, 의존성 버전, 사전 입력 manifest 해시, 시리즈/라이선스/달력 버전, 동결 UTC 시각을 기록한다. 미래 데이터 해시를 미리 만들 수 없으므로 입수 때 추가 전용 manifest로 기록한다.
5. 동결 뒤 첫 완전한 달의 시작 전에 초기 비중·학습입력·신호 시각을 기록한다. 사후 월말 정보를 이용해 같은 월 초에 진입한 것으로 계산하지 않는다.

평가기간 후보: **36개의 연속 월**. 운영 점검은 월별로 입력 누락·코드 오류만 확인하고, 비교 우열의 주 판정은 기간 종료 뒤 1회 수행한다. 36개월은 계획용 후보값이지 통계적 검정력이 확보됐다는 뜻이 아니다. 필요 표본·검정력 검토와 사용자 선택 전에는 동결하지 않는다. 실제 결과를 보며 조기 종료하거나 기간을 연장해 유리한 결론을 찾지 않는다.

실패 구분:

- 자료/실행 무결성 실패: 출처·시각 불명, 필수 월 누락, 해시 불일치, 미래 자료 사용, 입력/프로토콜 변경 → 실행 중지·INVALIDATED. 실패 구간을 조용히 제거하지 않는다.
- 성과 기준 미충족: 동결한 개선/열화 조건 미달 → 후보 미채택. 기존 정책 변경이나 자동 매도 아님.
- 불확실: 표본 부족·지표 미정·구간이 넓음 → INCONCLUSIVE. “차이 없음”이나 동등성 입증으로 바꾸지 않는다.

버그 수정도 새 버전과 영향 기록을 남긴다. 같은 평가 구간에 수정본을 재실행하면 원래 확증 결과를 대체하지 않고 별도 탐색 결과로 표시한다. 새 프로토콜은 새 미래 구간에서 시작한다. 운영자의 중간 결과 접근 여부도 기록하며, 접근했다면 미노출 주장을 철회한다. 이 문서 자체로 정보 차단을 기술적으로 보장하지 않는다.

## 6. 탐색 이력과 다중 비교

이미 확인한 탐색군: 5개 전략, 자산 포함/제외, 학습36/60/120개월, 비용0/10/30bp, 주기3/6/12개월, 주식 목표 고정 방어자산3종, FX 제거 반사실적, 블록3/6/12개월 각2000회. 전체 경우의 수는 실제 결과 JSON별로 세어야 하며 단순 곱셈으로 독립 실험 수를 만들지 않는다. 관련 #44~48 보고서를 보존한다.

기존 부트스트랩 구간은 실현 경로에 조건부인 탐색적 불확실성이다. 미래 우월 확률·미사용 표본·다중비교 보정 결과가 아니다. 모든 후보 결과와 중단·실패 실험을 함께 보관하고 최댓값만 발표하지 않는다.
