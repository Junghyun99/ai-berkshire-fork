# 위험균형의 낙폭 감소를 다시 검증하는 평가안

2026-11-14 KST · 검토용 초안 · 미사용 구간 개봉 전

[기존 평가계획](README.md)에서 후보 하나를 골랐다. 같은 5자산에서 위험균형이 동일가중보다 월말 최대낙폭을 줄이면서 위험조정수익률을 유지하는지가 연구 질문이다. [기존 탐색 결과](../20261114-strategy-decisions/README.md)는 가설을 고르는 데 이미 사용했다.

## 판정 기준 제안

차이는 모두 위험균형에서 동일가중을 뺀 값이다. 음수로 기록하는 MDD는 차이가 양수일 때 낙폭이 줄었다. 아래 숫자는 연구자가 제안한 판단 기준이다. 투자자의 효용이나 과거 표본에서 추정한 값이 아니며, 동결 전 검토 대상이다.

| 지표 | 제안하는 조건 | 선택 이유 |
| --- | --- | --- |
| 월말 MDD | 차이 ≥ +2.00%p | 고점 대비 손실률이 100원당 2원 이상 줄어야 방어 효과를 실질적으로 구분한다는 연구용 기준 |
| 연환산 Sharpe | 차이 ≥ 0 | 낙폭 감소를 위해 주된 투자 목표인 위험조정수익률을 희생하지 않는 엄격한 기준 |
| 연환산 Sortino | 차이 ≥ 0 | 하방위험 대비 성과도 유지되는지 독립적으로 확인 |
| CAGR | 두 값과 차이를 공개 | 낙폭 감소에 수반된 복리수익의 차이를 판단할 수 있게 한다 |

양쪽의 월별 비용 차감 KRW 수익률과 같은 KRW 단기금리 프록시를 사용한다. RF와 하방 목표는 매월 동일한 값으로 두고 계산식은 기존 계획 3절을 따른다. 경계값은 반올림 전 값에 적용한다. 세 조건을 모두 충족하면 해당 기간에 가설을 지지한다. 하나라도 미달하면 그 기간의 교체 제안은 보류한다. 지표 분모가 0이면 판정 불가, 누락·미래정보 사용·시점 증거 오류는 실행 무효로 기록한다. 단일 경로에서 세 조건을 만족해도 통계적 우월성을 주장할 근거는 별도로 필요하다.

## 평가 시점과 재현 조건

- 동일한 5자산, 월별 수익, 학습 60개월, 신호 공백 2개월, 연간 리밸런싱, 거래금액당 10bp를 양쪽에 적용한다. 최초 매수에도 비용을 부과한다. 자산별 비중과 주식·달러 노출을 함께 보존한다.
- 연속 36개월 종료 후 한 번만 판정하는 안이다. 시작은 동결 후 첫 완전한 달이고 가장 빠른 후보는 2026-12다. 자료가 늦어지면 시작을 순연한다. 검정력과 기간의 타당성은 동결 전 검토한다.
- 동결 시 금리 시리즈·빈티지·월 수익 변환·공표 지연, 체결 시점, 비용 처리, 입력 manifest와 코드 버전을 기록한다. 공식 한국 국채 총수익률과 과거 가용시점 검증 범위에 따라 결과에 연구 프록시 표시를 유지한다.
- 최종 수치 선택과 자료·엔진 요건은 [상위 계획의 동결 절차](README.md)를 따른다. 이번 문서는 실행 설정을 바꾸지 않는다. 새 가격이나 성과를 열람하지 않았다.
