## 네 가지 계산 경로

C는 비조정 종가, A는 수정종가, D는 해당 분배락일의 주당 총분배금이다.

1. 기존 수정주가: 일별 배수 A(t)/A(t-1).
2. Yahoo 분배금 역방향 조정 모델: C(t)/(C(t-1)-D_yahoo).
3. 공식 분배금 역방향 조정 모델: C(t)/(C(t-1)-D_issuer).
4. 공식 분배금 분배락일 종가 재투자: (C(t)+D_issuer)/C(t-1).

2→3은 금액 차이를, 3→4는 같은 금액에서 산출 방식 차이를 분리한다. 1→2의 작은 잔차도 별도 기록한다. 2번을 Yahoo 내부 알고리즘의 확정된 설명으로 취급하지 않는다. 4번은 실제 지급일 전에 재투자를 가정하므로 현실 체결 성과나 지급일 재투자 결과가 아니다. 기존 수정주가 수익률에 배당을 다시 더하지 않았다.
