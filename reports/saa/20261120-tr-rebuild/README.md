# SPY·IEF 총수익률 재구성과 전략 민감도

## 결론 — 2026-11-20 KST

PR #96의 재구성 코드를 다시 실행했다. 기존 2026-11-15 월별 산출물과 실행일을 제외한 전체 JSON이 일치했고, 회귀 테스트 6개가 통과했다. 이어 한국 자산 포함 기존 5자산 입력의 기준선과 두 가지 미국 ETF 수익률 대안을 재평가했다.

**이번 조건에서 CAGR·Sharpe·Sortino의 전략 순위와 리밸런싱 목표 비중은 유지됐다.** 재투자 방식까지 바꾼 경우 기준선 대비 CAGR 최대 절대 변화는 약 0.001526%p, MDD는 0.000695%p, Sharpe는 0.00015745, Sortino는 0.00037704다. 입력 차이가 기존 잠정 전략 비교 결론을 바꾼다는 증거는 없었다. 다른 기간·비용·모형에서의 불변성이나 미래 성과를 보장하지 않는다.

## 고정한 조건

- 자산: 한국 주식, S&P500, NASDAQ100, 한국 국고채10년, 미국 국채7~10년.
- 기존 한국 재구성 입력 179개월(2011-11~2026-09), 평가 117개월(2017-01~2026-09).
- 학습 60개월, 신호 공백 2개월, 12개월 리밸런싱, 비용 10bp, seed 17, 무작위 후보 2,500개.
- 최초 매수비용은 기존 기준선에 맞춰 제외(include_initial_cost=False). 실제 거래비용이 없다는 의미가 아니다.
- 기존 원화 환율과 한국 3개월 지연 금리 프록시를 유지했다. 후속 한국 금리 빈티지 보정과 초기매수비용 변경을 함께 적용한 실험이 아니다.
- 원래 엔진과 입력 파일을 변경하지 않고 SPY·IEF의 현지통화 수익률만 바꿨다. KRW 변환은 (1+r_local)×(1+r_fx)-1.
- 전체 전략은 각 시나리오에서 다시 학습했다. 기존 비중을 고정해 수익률만 대입한 실험이 아니다.
- 엔진·입력 SHA-256, 지표와 차이, 순위, 목표비중 차이는 strategy-summary.json에 기록했다.

기준선은 보존된 한국 재구성 실험의 다섯 전략 주요 지표와 월별 gross return에서 최대 오차 0, 목표 비중도 완전 일치했다. 동일가중·최소분산·shrinkage 최소분산·최대 Sharpe·위험균형을 비교했다.

## 입력 재구성

선행 [공식 분배 대조](../20261115-issuer-audit/README.md) 및 [SPY 단일 이벤트 검사](../20261115-spy-adjustment/README.md)를 따른다. 원본 URL·해시는 선행 results.json에 있으며 이 해시를 검증한 뒤 사용한다.

SPY·IEF 각각 일별 5,722행(2004-01-02~2026-09-30), 분배 92건·272건을 사용했다. 첫 월말을 기준으로 2004-02~2026-09 월간 수익률 272개를 재구성했다.

C=비조정 종가, A=수정종가, D=분배락일 주당 총분배금일 때:

1. 기존 수정주가 배수: A(t)/A(t-1).
2. Yahoo 분배 역방향 조정 모델: C(t)/(C(t-1)-D_yahoo).
3. 공식 분배 역방향 조정 모델: C(t)/(C(t-1)-D_issuer).
4. 공식 분배락일 종가 재투자: (C(t)+D_issuer)/C(t-1).

분배금 금액과 산출 방식의 영향을 분리했다. 2번을 Yahoo 내부 산출법으로 확정하지 않는다. 4번은 지급일 전에 재투자하는 지수형 가정으로 실제 체결 성과가 아니다. 수정주가에 배당을 다시 더하지 않았다.

| 비교 | SPY 월별 최대 절대 차이(bp) | IEF 월별 최대 절대 차이(bp) |
| --- | ---: | ---: |
| 기존 수정주가 → Yahoo 분배 역방향 | 0.008093 | 0.020353 |
| Yahoo 분배 → 공식 분배, 역방향 동일 | 0.077228 | 0.100852 |
| 공식 분배 역방향 → 분배락 종가 재투자 | 2.303325 | 0.586959 |
| 기존 수정주가 → 공식 분배락 종가 재투자 | 2.286877 | 0.661382 |

1bp=0.01%p. 각 비교의 최대 발생월이 달라 최대 차이를 단순 합산하지 않는다. 결과는 reconstruction-summary.json에 기록했다. 전략 평가는 1·3·4번을 사용했다.

## 전략 성과

아래는 공식 분배락일 종가 재투자 입력 결과다. CAGR·MDD는 %, ΔCAGR은 기준선 대비 %p이며 Sharpe·Sortino는 기존 원화 금리 프록시를 사용한다. MDD는 월말 경로 기준이다.

| 전략 | CAGR | ΔCAGR | MDD | Sharpe | Sortino |
| --- | ---: | ---: | ---: | ---: | ---: |
| 동일가중 | 13.288888 | +0.001526 | -17.000246 | 0.946913 | 1.596567 |
| 최대 Sharpe | 10.226441 | +0.000581 | -24.735209 | 0.712487 | 1.120026 |
| 위험균형 | 7.441338 | +0.000736 | -13.096552 | 0.697905 | 1.112272 |
| shrinkage 최소분산 | 4.444123 | +0.000482 | -13.724896 | 0.402661 | 0.605880 |
| 최소분산 | 2.273354 | +0.000630 | -14.278806 | 0.049066 | 0.070063 |

세 입력 모두 CAGR·Sharpe·Sortino 순서는 동일가중 → 최대 Sharpe → 위험균형 → shrinkage 최소분산 → 최소분산이었다. 다섯 전략 모두 두 대체 입력에서 목표 비중 최대 차이는 0이었다. 가격경로에 따른 리밸런싱 직전 비중 변화로 회전율은 소폭 달라졌다. 공식 분배락 재투자의 총 회전율 최대 절대 차이는 약 0.000097635 단위다. 10bp를 곱한 단순 비용률 합계 차이는 약 0.000000097635이며 최종 복리 자산가치 차이와 구분한다.

위험균형은 월말 MDD가 작았지만 동일가중보다 CAGR·Sharpe·Sortino가 낮았다. 이 입력 보완만으로 동일가중을 최적화 전략으로 교체할 근거가 생기지는 않았다.

## 재현

원본 ZIP 두 개는 기존 보존본을 사용한다: ai-berkshire-market-snapshot-20261029.zip, ai-berkshire-issuer-snapshot-20261115.zip. 한국 입력과 기준선은 ai-berkshire-korea-rebuild-20261029.zip의 experiment 디렉토리를 사용한다. 공개 재배포 권한 미확인 원본과 전체 월간 데이터는 커밋하지 않는다.

```bash
python3 reports/saa/20261120-tr-rebuild/rebuild.py --raw /path/to/issuer/raw --yahoo /path/to/snapshot-20261029/raw/yahoo --output /path/to/rebuilt-results.json
python3 -m unittest discover -s reports/saa/20261120-tr-rebuild -p test_rebuild.py -v
python3 reports/saa/20261120-tr-rebuild/compare_strategies.py --korea /path/to/korea-unpacked --rebuilt /path/to/rebuilt-results.json --output /path/to/new-output
python3 tools/report_audit.py extract --report reports/saa/20261120-tr-rebuild/README.md --dry-run
```

compare_strategies.py는 저장소 tools의 엔진을 사용한다. 이번 실행에서 사용한 엔진 해시는 strategy-summary.json과 같아야 한다. 기준선 재현 허용오차는 1e-10이며 목표 비중도 확인한다. 세 시나리오의 모든 gross return·turnover·target은 실행 시 full.json에 생성된다.

검증: 실제 재구성 exit 0, 전체 월별 출력 이전 실행과 일치, 회귀 6개 통과, 세 시나리오 백테스트 exit 0. 별도 saa_independent_check.independent_metrics로 120개 성과값 대조, 최대 오차 4.440892098500626e-16. 이 검사는 같은 수익경로의 산술 대조이며 독립 원천 인증은 아니다. 전체 저장소 테스트는 재실행하지 않았다. 보고서 감사 dry-run은 표본 추출일 뿐 독립 인증이 아니다.
