## 결론

KODEX 200은 공식 종가와 분배 기록으로 2010-01~2026-09 월별 수익률을 다시 계산했다. 한국 국고채10년은 공식 장기 가격 다운로드가 실패해 네이버 수정가격을 별도 대체 입력으로 사용했다. **전체 공식 TR 자료 확보 또는 운용 가능성 검증 완료가 아니다.** 기존 Yahoo 원본과 차단 규칙은 유지하며 새로운 실험 경로에서만 이번 입력을 사용한다.

5자산 공통 입력은 2011-11~2026-09 179개월, OOS는 2017-01~2026-09 117개월이다. 동일가중 CAGR은 13.29%, 월말 MDD는 -17.00%, Sharpe 0.947, Sortino 1.596이다. 기존 잠정 실험과 종합 성과 차이는 작지만, 월별 입력 결함은 실제로 있었으며 이를 방치할 수 없다. 이번에도 최적화 전략이 동일가중보다 높은 위험조정 성과를 보이지 않았다. 이 표본·설정에 한정한 관찰이며 일반적인 우열 판정은 아니다.

## 월별 결함과 수정

KODEX 공식 분배 기록의 지급기준일은 분배락일/지급일과 구분한다. 분배락일은 지급기준일 직전 운용사 가격 관측 거래일로 계산하고, 공식 가격의 전일 대비 증감액에서 확인되는 기준가격 조정과 대조했다. 증감액은 5원 호가 단위 반올림 영향을 받으므로 이를 현금 분배액으로 사용하지 않는다. 실제 분배액은 별도의 공식 분배 기록에서 가져온다. 확인되지 않은 조정·현금액 충돌·누락 거래일·해시 불일치는 실행을 중단한다.

- 공식 기록상 2022-07 지급기준일의 분배금은 70원이다. Yahoo에는 이 건이 빠져 있었다.
- Yahoo의 2022-10-27 85원 기록은 공식 해당 월 분배 표와 가격 기준 조정에 부합하지 않는다. 공식 2022-10 분배금은 105원이다.

## 계산 방식

미국 ETF 수정종가와의 비교를 위해 한국 주식의 기본 일별 성장률은 `P_t / (P_(t-1) - D_t)`로 계산한다. `P`는 운용사 관측 종가, `D`는 공식 현금 분배액이다. 월별 수익률은 이 성장률을 복리 연결한 계산 지수의 월말 비율이다. **계산 지수 100이라는 시작값은 정규화 값이며 실제 가격이나 추정 시장자료가 아니다.**

분배락일 종가 재투자 방식인 `(P_t + D_t) / P_(t-1)`도 별도로 계산해 대조했다. 두 방식의 한국 주식 월수익률 최대 차이는 약 **0.0330%p**다. 기본 수정가격 관행은 실제 현금 지급일에 재투자한 계좌 수익과 같지 않다. 네이버의 세부 조정 산식은 공식 인증되지 않았고 반올림 차이도 남는다. 원시 관측값, 계산 수익률, 금리 기반 추정 현금수익을 혼동하지 않는다.

원화 기준, 학습 60개월, 신호 공백 2개월, 12개월 리밸런싱, 편도 거래액 10bp 비용, 초기 투입 비용 제외, 롱온리·합계 1을 기존과 동일하게 적용했다. 금리는 기존 한국 3개월 은행간 연율의 3개월 지연값/1200을 사용한 **추정 현금수익 프록시**다. 실제 국채 무위험 실현수익으로 보지 않는다. MDD는 월말 기준이라 장중·일별 최대 손실을 나타내지 않는다.

## 남은 작업과 PR 상태

1. 한국 국고채10년 공식 장기 가격·전체 분배 기록 또는 공식 TR을 확보해 네이버 프록시를 교체/검증한다. 키움 공식 직접 조회는 503, 일부 대체 조회는 409/404, 삼성 추가 PDF 다운로드는 429로 실패해 무한 재시도하지 않았다.
2. 한국 주식의 분배락일은 공식 가격 달력으로 계산했으므로, 거래소 권리락 이벤트 원장과 독립 대조하면 검증을 강화할 수 있다.
3. 수정가격 관행과 실제 지급일 현금 재투자, 최초 매수 비용·세금·계좌 적격·입출금, 가용시점/빈티지, 독립 홀드아웃 검증은 남는다.
4. #41은 병합 완료. #42는 Draft 유지, #43의 원자료 차단은 유지. 이번 후속 PR은 #43에 의존한다. **코드 테스트 통과와 공식 데이터 검증 완료를 구분하며, 이번 결과를 이유로 IPS를 ACTIVE로 만들지 않는다.**
