## 독립 검산

`tools/saa_independent_check.py`는 기존 `saa_backtest.py`를 import하지 않는다. NumPy 공분산/벡터 계산, 별도 후보 생성 및 리밸런싱 구현, Pandas 원시 데이터 월별 집계를 사용했다.

- 원화 패널 최대 절대오차: 약 9.97e-17.
- 월 수익/거래량 경로 최대 절대오차: 약 2.22e-16.
- 120개 성과 항목 최대 절대오차: 약 8.88e-16.
- 같은 데이터·같은 알고리즘 가정의 구현 일치이며 모델 가정의 타당성 검증과 구별한다.
- IEF 2021~2025 연간 조정가격 수익률은 운용사 시장가격 수익률과 각각 0.01%p 이내로 일치. 공식 수치는 -3.33%, -15.16%, 3.64%, -0.63%, 8.03%.

## 발견한 원자료 문제

| 항목 | 확인 결과 | 처리 |
|---|---|---|
| KODEX 200 월말 | 2023-07-31 Yahoo quote null, 기존 월말은 07-28 사용 | 국내 포함 비교 보류 |
| KODEX 200 분배 | 2023-07-28 분배 75원, 전 거래일 quote null, 조정계수 반영 불명확 | 자동 보정 금지, 공식 가격/분배 자료 대조 |
| KODEX 200 2024-10 | 분배락일 quote null, 다음 날 조정계수 변화 | 무배당 조정 오류로 단정하지 않고 gap으로 분류 |
| KIWOOM 국고채10년 월말 | 2023-07-31 Yahoo quote null | 국내 포함 비교 보류 |
| SPY/IEF | 원본 범위의 배당조정 내부 검사 통과 | 미국 자산 부분집합 실험만 진행 |

공식 삼성자산운용 가격 엑셀은 2002-10-14부터의 시장 종가·NAV를 제공했고, 분배금 엑셀은 2021년 이후 20건을 제공했다. 이 두 파일을 다운로드·보존했다. **가격과 NAV 자체는 배당 재투자 총수익 시계열이 아니다.** 공식 가격을 구했다고 전체 TR 복원이 완료된 것으로 간주하지 않는다. 과거 전체 분배금/분배락일·다른 국내 ETF 자료는 추가 확보가 필요하다.

공식 엑셀의 2023-07-31 시장 종가는 34,635원, 기존 Yahoo 사용 값은 07-28의 34,480원이다. 공식 가격 경로와 75원 분배(금액은 운용사 확인, 분배락일은 Yahoo 07-28)를 사용해 분배락일 종가 재투자 방식으로 독립 계산하면 7월 시장가격 수익률은 약 **2.2095%**, 기존 패널은 **1.5312%**로 약 **0.6783%p 차이**다. 운용사 월간 PDF의 NAV 총수익은 2.25%이며 시장가격 수익과 구분한다. 이는 해당 월의 대조이며 전체 패널 수정본이 아니다.

기존 엔진의 “월말에서 7일 이내 마지막 값” 규칙은 미확인 거래일 결측을 허용할 수 있었다. 새 `saa_source_gate.py`는 공급자가 기록한 월 마지막 날짜의 quote 누락, 분배락일/직전 quote 공백, 조정계수 불일치를 차단한다. 공급자 날짜 검사이므로 거래소 달력 검증까지 완료한 것은 아니며, 실제 휴일인지 확인되지 않은 경우에도 보수적으로 중단한다. 과거 원본은 변경하지 않는다.

추가로 manifest의 소스별 경로를 고정하고 ticker/currency·timestamp/price 길이 불일치를 거부해 잘못된 파일에 대한 해시 확인만 통과하는 경우를 막았다. 테스트용 합성 가격은 단위 테스트에만 쓰고 실증과 분리한다.

## 미국 자산의 비교 조건 개선

원화 기준, 2009-04~2026-09의 동일 OOS. 60개월 학습, 2개월 신호 공백, 연 1회 리밸런싱, 거래액 기준 편도 10bp. 기준 금리 프록시는 기존 한국 은행간 3개월 금리의 3개월 지연값/1200을 유지했다. 실제 운용 가능 무위험 수익이라고 보지 않는다.

NASDAQ100 포함 동일가중은 미국 주식 2/3·미국 국채 1/3이고 SPY/IEF 동일가중은 주식 1/2·국채 1/2이다. 이를 단순한 NASDAQ 효과로 해석하지 않도록 **SPY 2/3·IEF 1/3** 기준선도 추가했다. 고정 60/40 역시 정책 제안이 아닌 비교 시나리오다.

SPY·IEF의 각 최적화 전략과 동일가중 간 Sharpe 차이를 월별 OOS 초과수익에 대해 12개월 블록 단위로 짝지어 1,000회 재표본화했다(seed 29). 이는 관측 수익의 조건부 통계 실험이며 가상의 가격을 생성한 것이 아니다. 전략 재학습·파라미터 탐색 불확실성은 포함하지 않는다.

## 재현 및 검증

```bash
python3 -m unittest discover -s tools/tests -v
python3 tools/saa_independent_check.py --root <원본경로> --full-results <기존-results-full.json> --output independent-check.json
python3 tools/saa_robustness_check.py --root <원본경로> --output us-robustness.json
python3 tools/saa_real_experiment.py --root <기존원본경로> --output <새경로>
# 마지막 명령은 국내 소스 문제가 해소되지 않으면 BLOCKED_SOURCE_RECONCILIATION으로 실패해야 한다.
```

추가 분석 의존성: NumPy 2.3.5, Pandas 2.2.3 (`requirements-research.txt`). 기본 엔진과 기존 테스트는 stdlib을 유지한다. 기존 146개 + 신규 입력 검증 6개 = **152개 통과**. #41의 파일 종료 수정은 main에 이미 반영되어 있으며 #42 기반 단독 테스트에서는 그 수정이 아직 포함되지 않는다.
