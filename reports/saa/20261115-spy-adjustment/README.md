# SPY 2021년 12월 분배금 차이 후속 검사

## 결론

#94에서 발견한 차이는 현재 발행사 XLSX만의 특이값이 아니다. 발행사가 2022-03-28 제출한 EDINET 공시에서도 2022-01-31 지급분이 주당 1.636431 USD로 기록된다. 기존 Yahoo 분배 이벤트는 1.633 USD다.

기존 원본의 분배락 전후 조정계수에서 역산한 금액은 약 1.633026 USD다. 따라서 표준적인 전일 종가 기반 역방향 배당조정 모델을 가정하면 수정주가도 Yahoo 이벤트에 가까운 금액을 반영한 것으로 해석된다. 이는 수치적 추론이며 Yahoo 내부 처리 원인이나 오류 발생 경로를 확정한 것이 아니다.

해당 이벤트 하나를 공식 금액으로 대체하는 조건부 민감도에서 SPY 2021년 12월 수익률 차이는 약 +0.07665bp다. 이 한 건의 직접 효과는 작지만 전체 데이터 품질 인증이나 포트폴리오 전략 순위 불변을 뜻하지 않는다. 엔진 입력은 변경하지 않았으며 #53·#54는 미완료다.

## 공시 근거와 시점

[EDINET S100NQRF](https://disclosure2dl.edinet-fsa.go.jp/searchdocument/pdf/S100NQRF.pdf)의 표지(p1)는 제출일 2022-03-28, 발행사 State Street Global Advisors Trust Company를 표시한다. p43의 분배 표에서 지급일 2022-01-31, 기준일 2021-12-20, 주당 1.636431 USD를 확인했다. PDF 본문 추출과 페이지 이미지로 확인했으며 이번 코드가 PDF를 자동 판독한 것은 아니다.

현재 State Street XLSX와 공시는 같은 발행사의 서로 다른 문서다. 독립된 두 발행사 검증이라고 표현하지 않는다. 기존 Yahoo 원본과 발행사 근거를 교차 대조한 것이다. 자료 접근일은 2026-11-15이며 기존 파일 해시는 results.json 및 선행 보고서를 따른다.

이 공시는 분배락 이후 제출됐으므로 2021-12-17 직전 투자 판단에서 그 금액을 알 수 있었다는 증거가 아니다. 최초 공표 시각, 중간 정정 여부, Yahoo 당시 빈티지는 여전히 미확인이다. 추정 분배금이 나중에 확정됐다는 설명도 근거 없이 채택하지 않는다.

## 계산과 의미

관측 종가를 C, 수정종가를 A, 조정계수를 k=A/C로 놓는다. 분배락 전일을 0, 분배락일을 1이라 할 때, 다른 조정이 없고 역방향 조정계수가 1-D/C0라면 다음이 성립한다.

- 역산 분배금: D*=C0×(1-k0/k1)
- 관측 일별 수익배수: A1/A0
- 공식 금액 가정 수익배수: (C1/C0)/(1-D공식/C0)
- 두 배수의 비율을 기존 12월 수익배수에 한 번 적용해 단일 이벤트 민감도를 계산한다.

| 항목 | 값 |
| --- | ---: |
| 2021-12-16 종가 USD | 466.45001220703125 |
| 2021-12-17 종가 USD | 459.8699951171875 |
| 역산 분배금 USD | 1.6330258438 |
| 공식 문서 분배금 USD | 1.636431 |
| 관측 12월 수익률 | 4.6247600630% |
| 조건부 12월 수익률 | 4.6255265287% |
| 12월 수익률 차이 | +0.0766465674bp |
| 해당 이벤트 통과 후 자산가치 비율 차이 | +0.0732585359bp |

후속 배당조정이 이전 가격 전체에 동일 배율로 적용됐다면 인접일 조정계수 비에서는 상쇄된다. 기존 파일의 분할 이벤트가 비어 있는 것도 확인하며, 분할 이벤트가 있으면 이 스크립트는 중단한다. 반올림·자료 정정·공급자 산출 관행은 별도 검증이 필요하다.

이 계산은 조건부 조정계수 민감도다. 실제 지급일 재투자나 분배락일 종가 재투자 모델과 동일하지 않으며 실제 운용성과도 아니다. 총수익률에 분배금을 다시 더하지 않았다. 실제 전략 전체의 CAGR·MDD·Sharpe·Sortino 재계산은 수행하지 않았다. 최초 공표 증거 없이 미래 확정액으로 과거 학습 입력을 교체하지 않는다.

## 재현·검증

Python 표준 라이브러리와 Decimal을 사용한다.

```bash
python3 check.py /path/to/snapshot-20261029/raw/yahoo/SPY.json results.json
python3 -m unittest discover -s . -p test_check.py -v
```

SPY 원본 SHA-256 불일치는 차단한다. 공식 금액은 위 공시에서 확인해 명시적으로 고정한 관측값이며 임의 생성값이 아니다. 기존 공개 시장가격 원본은 별도로 보존된 스냅샷을 사용한다.

실행: 실제 원본 분석 exit 0. 합성 테스트 3개 통과(알려진 조정계수 역산, 공통 배율 상쇄, 잘못된 가격 차단). 전체 저장소 테스트는 재실행하지 않았다. report_audit extract --dry-run은 표본 추출만 수행하며 출처 인증과 구분한다.
