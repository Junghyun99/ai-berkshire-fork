## 현재 판단

위험균형의 동일가중 대비 교체 제안은 보류한다. 기존 표본에서 낙폭 감소는 관찰했으나 Sharpe·Sortino까지 개선한다는 근거가 부족하다. 동일가중을 최적 전략이나 실제 투자안으로 확정하는 뜻도 아니다.

| 근거 | 관찰과 해석 | 한계 |
| --- | --- | --- |
| [총수익 재구성](../20261120-tr-rebuild/README.md) | 대체 재구성 입력에서도 기존 전략 순위가 유지됨 | 수치 재현이 공식 TR·시점 인증은 아님 |
| [시장 상황별 진단](../20261120-regimes/README.md) | 위험균형의 방어 효과와 위험조정수익 개선은 구분해야 함 | 사후 분류·겹치는 이동 구간은 독립 표본 아님 |
| [주식 목표 비중 통제](../20261120-equity-matched/README.md) | 같은 리밸런싱 주식 목표에서 내부 균등 배분 대비 위험균형의 추가 가치는 뚜렷하지 않음 | 연중 실제 비중·실현 위험은 다름 |
| [학습 예상 위험 통제](../20261120-risk-matched/README.md) | 현금을 혼합해 학습 위험을 맞춰도 단순 배분의 위험조정수익 우위가 유지됨 | 현금은 금리 프록시, 학습 위험은 실현 위험과 다름 |

위 관찰은 이미 확인한 과거 표본에 대한 것이다. 최종 배분 비중, 미래 우위, 통계적 우월성, 실제 운용성과로 확대하지 않는다. 새 숫자나 실험 결과를 추가하지 않았다.

## 이번에 마무리하는 범위

자산배분 방법론 비교의 현재 탐색 사이클을 잠정 정리한다. Phase 2 전체 완료나 모든 자료 검증 완료로 표시하지 않는다. 새 후보·파라미터를 계속 추가하는 작업은 현재 우선순위에서 내린다.
