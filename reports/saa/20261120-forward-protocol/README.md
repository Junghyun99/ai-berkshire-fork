## 연구 질문과 기준

[승인된 판정 기준](../20261101-evaluation-plan/risk-parity-comparison.md)과 [상위 평가계획](../20261101-evaluation-plan/README.md)을 실행 준비 항목으로 구체화한다. 이번 변경은 기준 재승인이나 투자정책 활성화가 아니다. 기계 판독 초안은 [protocol-draft.json](protocol-draft.json)이다. JSON은 실행기가 아니며 미정값을 기본값으로 대체해 실행해서는 안 된다.

| 구분 | 비교와 질문 | 지위 |
| --- | --- | --- |
| H1 | 같은 5자산의 위험균형이 동일가중보다 낙폭을 줄이며 위험조정수익을 유지하는가? | 기존 승인된 주 비교 |
| H2 | 같은 리밸런싱 시점의 주식 목표 비중에서 위험균형의 자산군 내부 배분이 추가 가치를 만드는가? | 탐색적 보조 비교; 성공 문턱 없음 |
| H3 | 학습 예상 위험을 현금으로 맞춰도 위험균형이 단순 배분보다 유리한가? | 탐색적 보조 비교; 성공 문턱 없음 |

H1의 차이는 위험균형−동일가중이다. 음수로 표현하는 월말 MDD 차이 ≥ +0.02, Sharpe 차이 ≥ 0, Sortino 차이 ≥ 0을 **반올림 전 모두 충족**해야 해당 기간의 가설을 지지한다. CAGR은 양쪽 값과 차이를 공개하되 별도 합격 문턱은 없다. 미달은 교체 보류, 분모 0은 판정 불가, 자료 누락·미래정보 사용·시점 증거 오류는 실행 무효다. 통계적 우월성이나 실제 투자 채택을 자동 의미하지 않는다.

H2는 연중 비중 표류로 실제 주식 노출이 달라질 수 있고, H3는 학습 위험 일치가 실현 위험 일치가 아니다. 최근 관측상 유리했던 동일가중+현금을 주 비교로 바꾸지 않는다. 보조 비교의 미래 재실행 여부와 구체 사양은 동결 전에 정하며 H1 판정에 섞지 않는다.

## 유지할 계산 조건

주 비교 자산은 KR_EQUITY, US_SP500, US_NASDAQ100, KR_TREASURY10Y, US_TREASURY7_10Y다. 월별 KRW 총수익, 학습 60개월, 신호 공백 2개월, 연간 리밸런싱, 거래금액당 10bp와 **최초 매수 비용 포함**을 유지한다. 과거 #96~98의 최초 비용 제외 결과와 새 평가의 차이를 표시한다. 월말 달력·환산·분배 재투자·비용 계산의 구체적인 실행 계약은 아래 동결 항목에서 고정한다.

매월 e=r−rf, Sharpe=mean(e)/sample_std(e)×sqrt(12), Sortino=mean(e)/sqrt(mean(min(e,0)^2))×sqrt(12)다. 양쪽에 같은 KRW RF를 적용하고 하방 목표도 같은 RF로 둔다. MDD는 초기 NAV=1을 포함한 월말 순자산에서 계산한다. CAGR=(종료 NAV/초기 NAV)^(12/월수)−1이며 최초 비용은 순자산에 반영한다. 현금 금리 프록시를 실제 투자 가능한 현금상품 수익으로 표기하지 않는다.

## 실행·판정 순서

1. 위 미정 항목을 채운 별도 실행 사양 PR에서 입력/코드 고정과 최초 비용·빈티지·시차·결측 차단을 합성 자료로 검증한다. 실제 학습 자료와 초기 비중까지 재현한다.
2. 모든 증거가 충족된 후 동결 레코드를 남기고 최초 평가 월 전에 초기 비중을 기록한다. 동결 후에야 미래 평가를 시작한다. PR 병합만으로 동결되지 않는다.
3. 매월 원본/빈티지·관측/가용/수집 시각·해시·목표/표류 비중·비용·수익률을 추가 보존한다. 미래 파일의 해시는 지금 생성하지 않는다. 데이터 무결성 점검은 허용하되 중간 성과로 후보/문턱/종료일을 조정하지 않는다.
4. 사전 고정한 연속 기간 종료 후 한 번 판정한다. 유리한 조기 종료·불리한 기간 연장·불리한 달 삭제는 금지한다. 버그가 있으면 원 기록과 영향 범위를 보존하고 무효 여부를 기록한다. 같은 기간 수정 재실행은 탐색 분석으로 구분한다.

이 문서는 동결 체크리스트이며 자동 스케줄러나 주문 실행기가 아니다. 현재 상태는 DRAFT, 실행 시작은 차단 상태다. 정책 v0.4 DRAFT 유지, 실제 계좌 관리는 후속 과제로 둔다.
