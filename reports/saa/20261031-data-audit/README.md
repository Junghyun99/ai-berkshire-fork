# 자산별 데이터 품질·기간 및 D01–D12 점검

기준일: 2026-10-31 KST. #53 부분 진행. **공식 한국 국채 장기 TR 미확보, 연구 프록시 유지.** 이번에 새 시장 시계열을 확보하거나 기존 성과를 갱신하지 않았다.

## 1. 이번에 실제 확인한 것

기존 개인 스냅샷을 읽기 전용으로 점검했다. 원본 manifest 8개·보완 manifest 16개 파일 해시, 가공 입력 2개 해시가 기존 QA와 일치했다. 자산별 월 관측과 공통기간, 가용시점 누락, 기존 차단기를 재실행했다. 세부 출력은 [snapshot-audit.json](snapshot-audit.json), 재현 코드는 [audit.py](audit.py)다. 해시 일치는 출처 진위나 이용권한 인증이 아니다.

- 재구성 입력: 1,254행 전부 research_proxy, available_at 1,254행 모두 누락.
- 5자산 공통 입력: 2011-11~2026-09, 179개월. 15년=180개월에 1개월 부족하며 20년=240개월과도 다르다.
- 기존 동일조건 OOS는 2017-01~2026-09, 117개월이다. 입력기간과 평가기간을 혼동하지 않는다.
- 초기 Yahoo 한국 ETF는 여전히 `BLOCKED_SOURCE_RECONCILIATION: 069500.KS,148070.KS`.
- 재구성 패널도 엄격한 `saa_data_quality.load_panel`에서는 `D08: unverified or unsourced data`로 차단된다. 별도 잠정 연구 실행 경로만 존재한다. quality 문자열을 verified로 바꾸지 않았다.

## 3. 공식 한국 국채 경로 재확인

- [키움 공식 상품 페이지](https://www.kiwoometf.com/service/etf/KO02010200M?gcode=148070)의 검색 본문에서 KIS KTB 10Y Index(TR), 국고채 10년물 3종목, ETF 상장일 2011-10-20, 지수 기준일 2010-09-01, 분기 교체 구조를 확인했다. 이것은 장기 일별 원본을 확보했다는 뜻이 아니다. 고정 만기 10년을 보유 내내 유지하는 단일 채권과도 다르다.
- 해당 공식 페이지를 웹 도구로 직접 열 때 timeout, Python 직접 요청에서 kiwoometf/kosef 두 주소 모두 HTTP 503이었다. 접근 실패는 이번 환경의 관측이며 서비스 전체 장애나 영구 접근 불가라고 단정하지 않는다.
- [KIS 공식 실시간지수 안내](https://www.bond.co.kr/conts/10051)를 웹 및 HTTP 200으로 다시 확인했다. 장기 자료/엑셀은 KIS-NET 로그인 경로를 안내한다. 인증 우회 또는 미확인 API 추측을 수행하지 않았다. 이번 작업은 상품 페이지 접근과 공식 접근 조건 재확인이며 새 일별 가격 다운로드 성공은 아니다.
- 지수 기준일은 약 16년 전이지만 해당 기간의 실제 값·산출 개정·라이선스는 미확보다. 20년을 채우려고 3년물 ETF나 합성 상장 전 값을 이어 붙이지 않는다.

직접 요청 상태·시각·KIS 응답 해시는 [access-attempts.json](access-attempts.json). 검색 본문은 2026-09 시점의 표를 포함하므로 최신 일별 시계열로 전사하지 않았다. 공식 안내가 요구하는 로그인/접근권과 이번 HTTP 실패를 각각 별개의 제약으로 기록한다.

## 5. 재개 조건·수집 계약

다음 자료 중 하나가 확보되면 새 스냅샷으로 검사한다.

1. 권한 있는 **KIS KTB 10Y 총수익지수** 날짜/값. 순가격 지수·YTM으로 대체하지 않는다. 통화, TR의 이자/재투자 정의, 바스켓 교체, 지수 기준일/첫 실제 관측일, 개정 이력, 사용/재배포 범위가 필요하다.
2. **148070 운용사 전체 일별 시장가격·NAV·분배 원본**. NAV와 시장가격을 분리하고, 분배락일/기준일/지급일/금액 및 조정 여부를 함께 받는다. 과표기준가격을 TR로 사용하지 않는다.

월말/달력 결측, 분배·조정계수, 연도별/월별 공식 성과를 대조한다. ETF 시장가격과 지수 TR은 비용·괴리·재투자 규칙이 달라 반드시 같은 수치라고 요구하지 않고 차이를 설명한다. 확보 후 기존 2017-01~2026-09·비용10bp·12개월 리밸런싱·동일 자산/학습 조건을 새 출력에서 재실행한다. 원본 #44~47 보고서를 덮어쓰지 않는다.

현재는 새 시계열이 없어 재실행 조건이 충족되지 않았다. #53의 공식 장기 자료·전수 대조·개선 자료 실험은 미결로 유지하며, 이번에 완료한 것은 출처/기간 현황과 D01–D12 대응표 및 저장 자료 무결성/차단 재확인이다. #54의 가용시점 계약 작업은 별도로 진행 가능하다.
