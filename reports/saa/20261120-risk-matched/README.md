# 학습기간 예상 위험을 맞춘 자산배분 비교

## 잠정 결론

[주식 목표 비중 통제](../20261120-equity-matched/README.md)에 이어, 과거 학습기간으로 계산한 변동성을 같게 맞췄다. 이번 표본에서 **현금을 섞은 동일가중은 위험균형보다 CAGR·Sharpe·Sortino가 높고 월말 MDD도 작았다.** 기존 위험균형을 선택할 추가 근거는 확인되지 않았다.

다만 맞춘 것은 리밸런싱 순간의 학습자료 기반 예상 위험이다. 미래에 실현된 변동성·베타·낙폭을 같게 만든 실험은 아니다. 현금의 수익률은 기존 원화 단기금리 프록시이며 실제 투자 가능한 현금 상품의 관측 수익률이 아니다.

## 가설과 계산 규칙

비교군은 원래 동일가중, 위험균형, 위험균형과 주식 목표 비중을 맞춘 자산군 내부 균등 배분이다. 기존 2017-01~2026-09 평가, 60개월 학습·2개월 신호 공백·연간 리밸런싱을 유지했다.

각 리밸런싱에서 당시의 세 목표 비중에 학습기간 자산수익률을 적용한다. 월별 포트폴리오 수익률에서 같은 월의 기존 원화 금리 프록시를 뺀 초과수익률의 표본 표준편차(ddof=1)에 sqrt(12)를 곱한다. 이를 각 배분안의 예상 변동성 sigma_i로 사용한다. 이는 매월 같은 비중을 적용한 학습 통계이며 해당 전략의 과거 실제 거래경로 변동성이 아니다.

세 값 중 최솟값을 공통 목표 sigma_*로 두고, 각 배분안에 다음을 적용한다.

- 기존 5자산 비중에 a_i=sigma_*/sigma_i를 곱한다.
- 나머지 1-a_i는 현금 프록시로 둔다.
- 따라서 0<a_i<=1이며 차입·레버리지를 사용하지 않는다.
- 이 비중으로 학습 초과수익률 변동성을 다시 계산하면 sigma_*와 같다.
- 다음 리밸런싱까지 현금과 자산 비중은 수익률에 따라 움직인다. 매월 목표 위험으로 되맞추지 않는다.

학습창은 평가월 t에서 [t-62,t-2)다. 목표·학습 종료월·각 sigma·축소 배율을 results.json의 audit에 기록했다. 전체 평가기간의 실현 변동성으로 목표를 정하지 않았다. 공통 목표는 이 세 후보의 상대 비교를 위한 설계 선택이며 사용자 위험 한도나 활성 정책이 아니다.

금리 프록시의 과거 공표·빈티지까지 인증한 것은 아니다. 이번 설계는 기계적 학습창 누수를 피하지만 point-in-time 검증 완료를 뜻하지 않는다.

## 현금과 비용

현금 월수익률은 기존 krw_rf_proxy를 사용한다. 3개월 지연 관측 연율 금리를 월수익률로 근사한 자료이며 실현 가능한 현금펀드 성과를 합성하지 않는다.

거래비용은 기존과 같이 5개 위험자산의 비중 절대변화 합에 비용률을 곱한다. 현금 자체 거래 수수료는 0으로 가정한다. 현금 이동을 위험자산 회전율에 다시 더하지 않는다. 최초 매수비용 제외를 유지하고 이후 재배분은 비용을 반영한다. 0·10·30bp를 각각 비교했다. 세금·대차비용·실제 상품별 수수료는 모델링하지 않았다.

위험균형의 학습 변동성이 모든 관측 리밸런싱에서 최솟값이어서 위험균형의 현금 비중은 0이었다. 이는 결과이며 처음부터 위험균형을 목표 위험으로 고정한 규칙은 아니다.

## 실제 계산 결과

아래는 공식 분배락일 종가 재투자 입력, 비용 10bp 결과다. 평가기간 2017-01~2026-09, 117개월. CAGR·MDD·실현 변동성은 %이고 현금은 월초 비중 평균이다.

| 배분안 | CAGR | 월말 MDD | 실현 연환산 변동성 | Sharpe | Sortino | 평균 현금 비중 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 동일가중 + 현금 | 9.9722 | -10.9299 | 8.1503 | 0.952404 | 1.628524 | 33.0688% |
| 주식 목표 일치 균등 + 현금 | 7.9535 | -12.1586 | 7.6998 | 0.761436 | 1.240805 | 11.1070% |
| 위험균형 | 7.4413 | -13.0966 | 7.7089 | 0.697905 | 1.112272 | 0% |

동일가중 + 현금은 위험균형 대비 CAGR 약 +2.5309%p, MDD 약 +2.1666%p였다. 실현 변동성은 약 +0.4414%p 높았으므로 이를 완전한 동일 실현 위험 비교라 부르지 않는다. 두 균등 배분안은 현금 혼합 후 주식 총비중이 다시 달라져 앞선 주식 비중 통제와는 별도의 실험이다.

기존 수정주가·공식 분배 역방향·공식 분배락 재투자의 세 입력 및 비용 0·10·30bp의 9개 조합 모두 Sharpe 순위는 동일가중 + 현금 → 주식 목표 일치 균등 + 현금 → 위험균형이었다. 새로운 미사용 데이터 검증이나 통계적 유의성 검정은 수행하지 않았다.

## 연구 판단

이번 두 통제 비교는 위험균형의 낮은 낙폭만 보고 내부 배분 알고리즘이 우수하다고 판단하기 어렵다는 근거를 보탠다. 간단한 균등 배분과 노출 축소도 중요한 비교군이다. 위험균형의 일반적 무효나 동일가중의 미래 우위를 입증하지 않는다.

다음에는 새로운 조합을 계속 탐색하기보다 다음 가설을 평가 계획으로 정리한다.

1. 위험균형 내부 배분이 단순 노출 축소보다 추가 가치를 제공하는가.
2. 학습 위험 추정 오차와 평가기간 선택이 이번 결론에 얼마나 영향을 주는가.
3. 기존 사전 평가 기준·미사용 구간에서 단순 기준선과 위험균형의 차이가 유지되는가.

과거 실험에 맞춰 새 채택 문턱이나 사용자 위험 한도를 정하지 않는다. 연구 기준선과 후보 역할을 정리하고 정책 승인은 분리한다.

## 재현과 검증


실제 실행 exit 0, 신규 합성 회귀 3개 통과. 학습 초과변동성 일치·비레버리지, 현금 수익과 위험자산 기준 회전율, 퇴화한 학습자료 차단을 확인했다. 모든 입력의 리밸런싱에서 축소 후 예상 위험 오차 <1e-12, 위험균형 성과는 선행 결과와 오차 <1e-12였다. 주식 비중 통제 회귀 4개는 별도 실행 기록이다. 전체 저장소 테스트는 재실행하지 않았다. report_audit dry-run은 표본 추출이며 독립 원천 인증이 아니다.
