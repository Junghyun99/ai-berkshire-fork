# 리밸런싱 시점의 학습자료 선택

2026-11-14 KST. [기존 빈티지 계약](README.md)을 백테스트의 각 학습창에 연결했다. 실제 미래 구간은 미개봉이다.

`python3 tools/saa_backtest.py --input realized.csv --training-vintages manifest.json --include-initial-cost`로 실행한다. realized.csv는 기존 검증 계약에 맞는 월별 실현 수익률 패널이다. manifest의 records는 해당 월의 완성된 KRW 총수익률을 소수로 담고, 환산·배당·가격 등 모든 구성 자료가 이용 가능했던 시각과 버전별 근거를 갖춰야 한다. 원시 금리 수준은 월 수익률로 변환한 뒤 입력한다.

| manifest 필드 | 내용 |
| --- | --- |
| decision_times | 리밸런싱 월 YYYY-MM → 결정시각. 해당 월의 한국시간 1일 0시 이하로 제한한다. 시작 NAV의 실제 가격이 더 일찍 결정되면 그 가격 이전의 컷오프를 사용해야 한다. |
| observations | 학습 월 → 시리즈 ID → 시간대 포함 관측시각. 관측시각은 해당 시리즈의 월 기준 시간대로 기재한다. |
| records | [빈티지 계약](README.md)의 관측값, 공개·가용시각, 버전과 증거 참조. 같은 관측의 수정본은 별도 행이다. |
| rf_series_id, evaluation_rf | 금리 반영 CLI 실행 시 두 필드를 함께 제공한다. 전자는 학습용 월 RF 빈티지의 시리즈 ID, 후자는 패널 전체 월 → 실현 월 RF 수익률이다. RF 지표를 비교하는 승인 실험에는 두 필드가 필요하다. |

필수 관측이 누락되면 실행을 중단한다. 결과의 training_vintage_audit에서 결정별 선택 값과 증거를 추적한다. 실현 수익률은 성과와 리밸런싱 전 비중 계산에 사용한다. 당시 체결가격과 비중의 가용성, 금리·환율 변환 재현성, 출처 진위는 별도 검증 대상이다. 월 경계 검사는 거래소별 체결 가능성을 인증하지 않는다.

검증은 합성 자료로 실시했다. 늦게 공개된 수정본, 다음 리밸런싱에서의 금리 누락, 월 시작 이후 컷오프를 시험했다. 기존 [자료 감사](../20261031-data-audit/README.md)에 기록된 1,254행의 가용시각 누락은 남아 있다. 이 변경으로 해당 행을 인증하거나 실제 성과를 다시 산출하지 않았다.
