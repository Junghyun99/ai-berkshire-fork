## 6. Phase 2-4로 넘길 요구사항

이 문서는 다음 단계 입력을 정리하며 구현 착수나 숫자 확정을 의미하지 않는다.

1. **현금흐름 계약:** 납입·인출 시각/통화/계좌, 외부 입출금과 계좌 간 이전 구분. 입출금을 투자손익으로 세지 않는 TWR 및 투자자 MWR 계산, 인출 시 유동성 부족·매도 비용 검증. 금액·주기·비상자금은 사용자 미확정값으로 둔다.
2. **계좌별 제약:** 일반계좌·ISA·연금저축·IRP의 상품 적격·위험자산·세금·인출 규칙을 출처/효력일/금융사와 함께 별도 모델링. 현재 법정 한도나 사용자 잔고를 이 보고서에서 추정하지 않는다.
3. **레버리지:** 일별 재설정·실효 노출·비용·경로 의존을 반영한다. 월 수익률을 단순 배수로 늘리는 것을 실제 ETF 성과로 취급하지 않는다.
4. **평가 기준:** 기존 동일가중·고정 목표 기준선을 유지하고, 동일 현금흐름·비용·기간에서 비교한다. 합성 스트레스와 관측 데이터 시뮬레이션을 분리한다.
5. **승인 경계:** 한국·미국·혼합 방어자산은 연구 후보다. 60/40·30/30/20/20·레버리지 한도는 확정 투자정책이 아니다. 연구 코드의 PR 병합도 IPS 활성화나 주문 권한을 부여하지 않는다.

## 7. 근거·재현·이번 문서 검증

수치의 원본은 연결된 보고서 및 각 `results-summary.json`이다. `evidence-index.json`에 이번 문서가 참조한 파일 SHA256과 조회한 PR 상태를 기록한다. 원시 자료는 기존 개인 재현 ZIP에 보존하고 GitHub에는 원시자료를 중복 공개하지 않는다. 구체 명령과 계산 방식은 각 실험 보고서에 있다.

이번 변경은 문서와 증거 색인만 추가한다. 새로운 백테스트·정책 변경·법률 규칙 확정은 하지 않았다. 표는 기존 JSON에서 생성했고 기간 117개월·18개 불확실성 구간의 0 포함을 기계 대조했다. 로컬 상대 링크와 `git diff --check`, `report_audit extract --dry-run`을 확인한다. 문서 변경에 전체 테스트를 재실행하지 않았으며 180개 통과는 위 기존 실행 기록을 인용한다.
