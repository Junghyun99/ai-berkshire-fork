# 주식 목표 비중을 맞춘 위험균형 비교

## 잠정 결론

위험균형의 방어 성과가 자산군 내부의 복잡한 배분 때문에 생겼는지 확인하기 위해, **리밸런싱 시점의 주식 총비중을 위험균형과 똑같이 맞춘 비교안**을 만들었다. 주식 3종 안에서는 균등, 국채 2종 안에서도 균등 배분했다.

2017-01~2026-09의 같은 평가에서 이 비교안은 위험균형보다 CAGR·Sharpe·Sortino가 높고 월말 최대낙폭도 작았다. 반면 연환산 변동성은 더 높았다. 위험균형의 낮은 낙폭을 그 내부 배분 방식의 고유한 우월성으로 설명할 근거는 이번 비교에서 확인되지 않았다.

이 결과는 주식 비중을 맞춘 통제 비교이며 동일 위험 비교가 아니다. 비교안 역시 위험균형이 산출한 주식 목표 비중에 의존하므로 완전히 독립적인 단순 전략이나 승인된 배분안이 아니다.

## 비교 설계

선행 [시장 상황별 진단](../20261120-regimes/README.md)에서 위험균형이 동일가중보다 낙폭을 줄이는 대신 상승 참여가 낮았음을 확인했다. 이번에는 주식 총비중과 자산군 내부 배분을 분리한다.

- 기존 5자산: 한국 주식·S&P500·NASDAQ100·한국 국채·미국 국채.
- 학습 60개월·신호 공백 2개월·12개월 리밸런싱, 평가 117개월(2017-01~2026-09).
- 비용 10bp, 초기 매수비용 제외, 기존 KRW 환율 및 3개월 지연 금리 프록시 유지.
- 원래 동일가중: 각 자산 20%, 따라서 리밸런싱 시 주식 목표 60%.
- 위험균형: 기존 후보 격자에서 위험기여도 편차를 줄이는 근사 방법. 정확한 전역 최적 위험균형 해라고 주장하지 않는다.
- 비교안: 그 시점 위험균형 목표의 주식 3종 비중 합을 E라고 할 때 각 주식 E/3, 각 국채 (1-E)/2.
- E는 선행 실험의 과거 학습창으로 계산된 목표를 이용했다. 평가 전체의 최적 비중·실현 변동성을 보고 E를 고르지 않았다.
- 매월 수익률로 비중이 변하고, 정해진 연간 리밸런싱에서만 목표를 다시 적용한다. 실제 비중 변화로 회전율을 다시 계산하며 비용을 한 번 반영한다.
- 기존 수정주가, 공식 분배 역방향 조정, 공식 분배락 종가 재투자 세 입력 모두 실행했다. 아래 표는 공식 분배락 종가 재투자 결과다.

과거 원자료의 최초 공개 시각은 미검증이다. 학습창 분리는 당시 접근 가능한 데이터였다는 인증과 구분한다.

## 성과 비교

단위: CAGR·MDD·변동성은 %, 나머지는 비율. MDD는 월말 경로 기준이다.

| 항목 | 원래 동일가중 | 위험균형 | 주식 목표 비중을 맞춘 균등 배분 |
| --- | ---: | ---: | ---: |
| CAGR | 13.2889 | 7.4413 | 8.5516 |
| MDD | -17.0002 | -13.0966 | -12.8847 |
| 연환산 변동성 | 11.7318 | 7.7089 | 8.2924 |
| Sharpe | 0.946913 | 0.697905 | 0.779270 |
| Sortino | 1.596567 | 1.112272 | 1.271138 |
| 총 회전율 | 1.164495 | 1.699043 | 1.163980 |

비교안은 위험균형보다 CAGR 약 +1.1102%p, MDD 약 +0.2119%p, Sharpe +0.08137, Sortino +0.15887였다. 연환산 변동성은 약 +0.5835%p 높았다. 원래 동일가중과 비교하면 두 방어형 배분 모두 CAGR과 위험조정 수익률은 낮고 낙폭은 작다.

세 입력 시나리오 모두 이 방향은 유지됐다. 전체 수치·입력/엔진 해시·각 리밸런싱의 비교안 목표는 results.json에 기록했다.

## 비중 일치의 범위

위험균형 주식 목표 비중은 각 리밸런싱에서 약 26.52~41.06%였다. 비교안도 해당 시점에 정확히 같은 주식 총비중을 사용한다. 원래 동일가중의 60%와는 상당히 다르다.

그러나 다음 리밸런싱 전까지 자산별 수익률이 달라 주식 총비중도 달라진다. 공식 분배락 재투자 입력에서 월초 주식 총비중 차이는 최대 약 2.1907%p였고 월초 평균은 위험균형 36.5159%, 비교안 36.8038%였다. 따라서 매월 동일 주식 노출이나 동일 베타·듀레이션·환율위험을 유지한 실험은 아니다.

동일 주식 목표에서도 내부 국가·지수 배분, 채권 배분, 드리프트, 회전율과 비용이 함께 바뀐다. 이번 결과만으로 각 요인의 인과 기여도를 숫자로 확정하지 않는다.

## 36개월 구간 진단

겹치는 36개월 창 82개에서 위험균형이 비교안보다 높은 지표를 기록한 횟수:

| 지표 | 위험균형 우위 창 수 |
| --- | ---: |
| CAGR | 3 / 82 |
| MDD | 34 / 82 |
| Sharpe | 6 / 82 |
| Sortino | 9 / 82 |

세 입력의 승수는 같았다. 창은 서로 겹치며 독립 표본이 아니다. 미래 승률이나 통계적 유의성으로 해석하지 않는다. 전체 구간에서 비교안이 앞섰다고 모든 하위 구간에서 앞선 것도 아니다.

## 방법론상 판단

1. 위험균형의 방어 성과를 평가할 때 주식 총비중이 낮다는 점을 함께 설명해야 한다.
2. 같은 주식 목표 비중에서도 단순한 자산군 내부 균등 배분이 경쟁력 있는 비교군이었다.
3. 위험균형은 변동성을 더 낮췄으므로 이번 결과만으로 방법론 전체를 폐기하지 않는다.
4. 동일가중은 연구 기준선, 위험균형과 이번 비교안은 방어 강도 및 수익 희생을 비교하는 후보로 유지한다. 최종 투자안 채택은 아니다.

다음은 **학습구간 변동성으로만 위험 수준을 맞추는 별도 비교**다. 같은 주식 비중이 같은 위험을 뜻하지 않으므로 위험조정 후에도 성과 차이가 유지되는지 확인해야 한다. 전체 평가기간 실현 변동성으로 사후 레버리지를 정하는 방법은 사용하지 않는다. 현금 비중·금리·추가 거래비용·레버리지 허용 여부는 실행 전에 설계로 명시해야 한다. 이번 작업에서는 이러한 추가 가정을 적용하지 않았다.

## 재현·검증

선행 PR #96의 재구성 및 전략 비교를 먼저 실행해 rebuilt-results.json과 full.json을 생성한다. 보존된 한국 재구성 ZIP의 experiment 입력을 사용한다. 기존 원본·엔진·정책을 변경하지 않았다.

```bash
python3 reports/saa/20261120-equity-matched/compare.py --korea /path/to/korea-unpacked --rebuilt /path/to/rebuilt-results.json --comparison /path/to/full.json --tools-dir tools --output /path/to/matched-results.json
python3 -m unittest discover -s reports/saa/20261120-equity-matched -p test_compare.py -v
python3 tools/report_audit.py extract --report reports/saa/20261120-equity-matched/README.md --dry-run
```

실제 실행 exit 0. 위험균형 수익경로와 회전율을 다시 계산해 선행 결과와 최대 오차 0을 확인했다. 합성 회귀 4개 통과: 그룹 비중 보존, 드리프트·회전율 산술, 잘못된 패널 차단, 미래 목표의 조기 적용 차단. 전체 저장소 테스트는 재실행하지 않았다. 보고서 감사 dry-run은 표본 추출이며 원천 인증이 아니다.
