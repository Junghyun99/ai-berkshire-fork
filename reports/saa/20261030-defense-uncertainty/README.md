# 방어자산 성과 차이의 불확실성 — 2026-10-30

## 결론

#46에서는 미국 국채 구성의 Sharpe·Sortino가 높고 혼합 구성의 월말 MDD가 작았다. 그러나 이번 탐색적 재표본화에서는 **모든 비교의 Sharpe·Sortino 차이 95% 구간에 0이 포함**되었다. 3/6/12개월 블록에서 모두 동일하다. 관측된 순위를 지우는 결과는 아니지만, 안정적 우위나 미래 초과성과를 확정할 근거로 삼기 어렵다. 구간에 0이 포함된다고 전략이 동등하다는 증명도 아니다.

## 입력과 방법

한국 주식 30% + S&P500 30% 목표를 공통으로 둔 #46의 한국 국채 40%, 미국 국채 40%, 한국·미국 국채 각 20% 세 구성만 비교한다. 실제 비중은 리밸런싱 사이에 드리프트한다. 기본 12개월 리밸런싱·10bp 거래비용·최초 투자비용 제외, 2017-01~2026-09 117개월의 **실현된 비용 차감 후 월 수익률**을 재생성했다. 기존 독립 NumPy 계산으로 기본 성과 24개 항목을 다시 대조했다.

- 방법: paired circular block bootstrap, 고정 길이 블록의 끝을 표본 처음으로 연결하고 마지막 블록을 117개월 길이에 맞춰 자른다. [arch 공식 문서](https://bashtage.github.io/arch/bootstrap/generated/arch.bootstrap.CircularBlockBootstrap.html)의 방법 설명을 참고한 자체 구현이며 arch 패키지에 의존하지 않는다.
- 블록 길이 3/6/12개월, 각 2,000회. seed=20261030, 길이별 seed는 기본값+블록 길이. NumPy 버전은 결과 JSON에 기록한다. 결과가 유리한 길이를 선택하지 않았다.
- 같은 추출 인덱스를 세 포트폴리오와 RF에 함께 적용한다. 따라서 같은 달 자산 간 동조와 RF 대응을 유지한다. 블록 내부 순서를 유지하지만 블록 경계의 장기 의존과 구조 변화는 보존하지 못한다.
- 각 재표본에서 연율화 Sharpe 및 Sortino(RF)를 계산하고 구성 간 차이의 2.5/97.5 백분위수를 기록한다. RF는 기존 3개월 지연 한국 은행간 연금리/1200의 월 현금수익 추정값이다.
- 재표본 경로는 **통계 실험용 합성 재표본**이다. 실제 시장 관측자료를 새로 수집하거나 과거 가격을 생성한 것으로 취급하지 않는다. 기존 시장 입력 파일은 수정하지 않았다.

## 해석 한계와 다음 판단

이 검증은 이미 실현된 월별 순수익 경로에 조건부다. 재표본화된 기초자산 위에서 비중·거래비용·리밸런싱을 다시 계산한 실험이 아니며, 전략 선택이나 모수 추정 불확실성까지 포괄하지 않는다. 순환 연결은 표본의 마지막과 처음을 붙이는 인공 경계를 만든다. 정상성·약한 의존성 근사가 긴 시장 구조 변화에 적합한지도 확정되지 않았다. 블록 길이는 민감도 진단용이며 최적 길이 추정값이 아니다.

다중 비교 보정이나 사전 등록을 하지 않은 탐색 분석이다. 같은 표본을 여러 차례 확인했고 미사용 홀드아웃이 없으므로 통계적 발견 확정에 사용하지 않는다. 이번에는 CAGR·MDD 구간을 추가하지 않았다. 특히 낙폭은 경로 순서에 민감하므로 임의 재배열 구간을 미래 손실 한도로 해석하지 않는다. 기존 월말 MDD 비교 자체는 #46에 그대로 보존한다.

**현재 연구 판단:** 성과 지표만으로 한국 국채를 제외하거나 미국 국채로 방어자산을 확정하지 않는다. 한국 국채·미국 국채·혼합을 후보로 남겨 두고, 한국 국채 공식 장기 원본 검증과 실제 원화 인출 필요·계좌 적격성·환율 위험을 후속 평가한다. 이 문장은 연구 범위 판단이며 투자정책 승인이나 사용자 확정 비중이 아니다.
