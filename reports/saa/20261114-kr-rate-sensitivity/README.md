2026-11-14 KST · 공개 자료 기반 연구 프록시 · 평가 구간 2017-01~2026-09, 117개월

## 이번에 적용한 가정

각 평가월 시작 이틀 전 ALFRED 보관본에서 3개월 전 관측값을 찾았다. 없으면 그 이전의 가장 최근 관측값을 사용했다. 이 대체 규칙은 이번 민감도 계산에서 연구자가 선택했다. 2019-04는 2018-12 금리, 2024-04는 2023-12 금리를 사용했다. 연율 퍼센트를 1200으로 나누는 기존 월 현금수익률 근사를 적용했다. 금리로부터 계산한 추정 수익률이며 실제 현금상품의 운용성과를 측정하지 않는다.

CAGR·월말 MDD 차이는 모든 전략에서 0이다. 금리는 초과수익 지표의 기준과 최대 Sharpe 비중 선택에 사용된다. 최대 Sharpe의 과거 비중을 다시 계산해 기존 10회 목표 비중과 일치함을 검증했다. 나머지 네 전략의 비중 산식은 RF를 사용하지 않는다. 거래비용 10bp, 최초 매수비용 제외 등 원래 비교 조건을 적용했다.

## 검증과 재현

기존 보관 파일 ai-berkshire-korea-rebuild-20261029.zip의 experiment 디렉터리를 복원했다. 기존 월별 총수익·회전율·RF에서 5전략의 CAGR·MDD·Sharpe·Sortino 20개를 다시 계산하여 저장 결과와 오차 1e-10 이내임을 확인했다. 원 실험 설정은 학습 60개월, 신호 공백 2개월, 연간 리밸런싱, 후보 seed 17과 무작위 후보 2500개다. 계산 코드는 기준 커밋 2fd93dc21b6e46a873c3ffc91bb3a72aadded4e8의 saa_backtest다.

[재계산 스크립트](recalculate.py)와 [정밀 결과 및 117개월 근거](results.json)에 원 입력 해시·보관본 URL·원문 해시·선택 관측월·금리값·10회 비중 대조를 보존했다. 이전 [연간 보관본](../20261101-availability/kr-rate-windows-evidence.json)을 함께 사용한다.

```bash
python3 reports/saa/20261114-kr-rate-sensitivity/recalculate.py   --repo . --experiment /path/to/experiment   --evidence reports/saa/20261101-availability/kr-rate-windows-evidence.json   --cache /path/to/archive-cache --output /path/to/recalculated.json
```

입력 ZIP SHA-256은 29f2241df72961ffaedd0fff022aabc10f75a0111144d9259c00ea0adb63d66b이다. 최초 실행은 FRED/ALFRED 공개 CSV를 수집하고 이후 실행은 캐시를 사용한다. 공개 데이터 제공 내용이 바뀌면 결과의 해시를 대조해야 한다.

자료 범위는 한국 RF 시리즈다. 월초 이틀 전 기준은 보관일 이후 개정을 제외하는 보수적 가정이며 최초 공표 장중 시각 인증은 남아 있다. 가격·총수익률·환율의 과거 버전 검증도 별도 과제다. 이번 결과는 기존 탐색 표본의 데이터 민감도이며 새 미래 구간 평가가 아니다.
