1. **과거 판단·교훈 조회**: 같은 종목 과거 판단 2건이 있다(2026-11-01 team, 11-07 checklist, 모두 관망 ★3·150~200 USD, 미정산). 당시 반증 조건을 Q3 8-K로 채점하면 둘 다 미발동이다. 산업 교훈은 없었다.
2. **팩트시트**: `fact_sheet.py NVDA`로 만들었다. 연간 재무의 SEC EDGAR 교차 검증은 전 항목 ✅였다. 시가총액 검산은 3.30% 편차(⚠️)였다.

6. **리스크 토론**: 1라운드는 세 성향 Agent가 병렬로 제안했고, 2라운드는 Team Lead가 대리 작성했다. 1차를 140달러(1.0%, 10-Q 확인 조건)로 현실화하고, 신규 매수 금지선을 내재가치 상단 190으로 낮췄다.
