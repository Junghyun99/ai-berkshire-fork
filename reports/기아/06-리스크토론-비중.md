## 2. 1라운드 (병렬)

- **공격형**: 상한 2.5% 유지(★2에서 상향 불가). 현재가가 1차 아래라 1차는 "재검토 트리거"로 재정의하고 1.0%로 상향, 4Q26 영업이익률 6% 이상 확인 시 100,000원 이하 선집행 허용. 2차 85,000원 0.75%, 3차 73,100원 0.75%(꼬리용).
- **보수형**: 상한 2.0%(관세 기저 제외 3Q 영업이익 -1,770억). 1차 95,600원 0.5%(4Q26 확인 후), 2차 81,300원(3년 최저) 0.75% — 84,400원은 52주 최저 87,100원 바로 아래라 변별력 약함, 3차 73,100원 0.75%. 반증 조건 우선 단계 축소.
- **중립형**: 상한 2.5% 유지(올릴 근거도 내릴 근거도 없음). 가격 조건은 충족됐으나 확인 신호(마진) 미충족 → 4Q26 확인 전 집행 금지, 확인 후 현재가 부근 0.75%, 2차 84,400원 0.75%, 3차 73,100원 0.5%.

## 3. 2라운드 (상호 반박·인정, 1회)

### 공격형
- 보수형 지적 수용: 2차 85,000원 안 철회, 84,400원 기준선으로. 상한 2.0%는 4Q 확인 전 보류로 이미 처리된 마진 불확실성을 이중 차감한다고 반박. 중립형의 3차 축소는 수용, 1차 0.75%는 합계가 상한에 못 미친다고 반박.
- **제안 실행 계획**: 비중 상한 2.5% | **분할 매수**: 95,600원 1.0%(4Q26 영업이익률 6% 이상 확인 후, 100,000원 이하 집행 허용) / 84,400원 0.75% / 73,100원 0.75%(꼬리용) | **축소 검토**: 기준선 유지 | **현재 상태**: 대기(4Q26 마진 확인 전 집행 보류)

### 보수형
- 공격형의 100,000원은 내재가치 하단 95,000원을 넘는 가격이라 안전마진이 아니라고 반박. 지연 비용은 기회비용이지 영구 손실이 아니라고 보되, 1차 0.75%는 수용. 중립형의 "현재가 부근" 진입은 차수를 하나 더 만드는 셈이라고 반박, 3차 0.5%는 동의. 상한은 2.0%, 4Q 확인 시 2.5% 복원으로 수정.
- **제안 실행 계획**: 비중 상한 2.0%(4Q26 영업이익률 6% 이상 확인 시 2.5%) | **분할 매수**: 95,600원 0.75%(4Q26 확인 후) / 81,300원 0.75% / 73,100원 0.5% | **축소 검토**: 반증 조건 발생 시 가격과 무관하게 단계 축소, 149,500원 이상 1/3·169,000원 이상 추가 | **현재 상태**: 대기(4Q26 실적 확인 전 집행 보류)

### 중립형
- 공격형의 1차 1.0%는 근거 데이터가 없고(상한의 40%를 앞쪽에 쏠림), 100,000원 선집행은 내재가치 하단·1차 가격(95,600원)보다 높아 규칙 위반이라 반박. 보수형의 2차 81,300원(관측된 3년 최저)과 반증 우선 축소는 수용. 상한 2.0%는 방향 근거뿐이라 반박(확인 전 집행 0%로 위험 통제).
- **제안 실행 계획**: 비중 상한 2.5% | **분할 매수**: 95,600원 이하 0.75%(4Q26 영업이익률 6% 이상 확인 후, 현재가 88,200원 포함) / 81,300원 0.75%(확인 후) / 73,100원 0.5% | **축소 검토**: 기준선 + 반증 조건 발생 시 즉시 단계 축소 | **현재 상태**: 대기(4Q26 마진 확인 전까지 집행 보류)
