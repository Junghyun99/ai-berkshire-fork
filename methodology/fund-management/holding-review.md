# 보유 이후의 추가 매수·유지·축소 검토

2026-11-28 · Phase 3 연구 방법. 현재 판단 시각에 이용 가능한 기존 기업 보고서, 최신 공시, 가격과 연구용 보유 상태를 한 시점에 맞춘다. 보유 상태에는 현재 평가액, 비중 분모, 차수별 기사용액, 이전 축소 검토 이력, 가용 현금을 포함한다. 주가 변동만으로 이미 소진한 차수가 다시 열리지는 않는다.

| 무엇이 변했나 | 이번 판단 | 판단 기록에 남길 내용 |
|---|---|---|
| 가격이 하락했고 투자 논지가 유지됨 | 미사용 차수의 가격·사업 조건이 충족되면 추가 편입 검토 | 해당 차수 잔액, 종목·이벤트 한도까지의 여유, 현금 중 최솟값. 다른 후보와 현금을 공유하면 동시 배정 검토 |
| 반증 조건이 확인됨 | 가격에 관계없이 추가 편입을 멈추고 축소·유지·전량 제외를 재평가 | 어떤 공시가 어느 가정을 깨뜨렸는지, 갱신한 가치 범위와 잔존 논지. 감액 크기는 별도 판단 |
| 핵심 공시가 없거나 지표 정의가 불일치 | 기존 보유는 잠정 유지하고 추가 판단을 보류 | 부족한 근거, 다음 확인 사건. 근거 부족과 논지 유지 판단을 구분 |
| 논지는 유지되지만 가격이 축소선에 도달 | 가치 대비 안전마진과 축소 차수를 재검토 | 적용할 보고서 버전, 축소 비율의 분모, 기존 검토·반영량. 새 가격·가치 정보로 판단이 달라지면 이유 기록 |
| 논지·가격·포트폴리오에 의미 있는 변화가 없음 | 유지 | 다음 검토 조건. 단순한 날짜 경과로 매수·축소를 반복하지 않음 |
| 종목 외부에서 비중 초과나 더 나은 신규 후보가 생김 | 위험 축소·교체를 별도로 비교 | 기존 기업 자체의 논지 변화와 분리해 [재원 조달 대안](replacement-funding.md)을 검토 |

## 같은 어도비를 다른 조건에서 검토

[기준 보고서 §7](../../reports/어도비/최종보고서.md#L143)에서는 가이던스 전 노출을 1%로 제한했다. 두 번째 가격은 235달러, 네 번째 가격은 274.12달러 이하이며 4차에는 FY27 매출 가이던스 +7% 이상과 유기 ARR 성장률 8% 이상이 모두 필요하다. 첫 축소 검토선은 380달러다.

아래는 각각 독립적인 가상 상황이다. 첫 차수를 이미 사용했고 현재 보유 평가액은 10만 원, 주식 예산 1,000만 원, 가용 현금 20만 원으로 가정한다. 원문에서 비중 분모가 확정되지 않아 이 사례에서만 주식 예산을 사용한다. 이벤트 결과와 다음 가격은 가정값이며 실제 발표나 매매 기록이 아니다. 다른 반증·추가 중단 조건은 언급된 경우 외에는 없다고 가정한다.

| 비교 상황 | 판단 | 산술·이유 |
|---|---|---|
| 발표 전, 235달러. 2차 미사용 | 유지 | 2차 가격에 도달했지만 현 보유액이 이벤트 전 한도 10만 원에 도달. 추가 0원 |
| 발표 후, 274.12달러. 가이던스 +7%, 유기 ARR +8%, 4차 미사용 | 추가 15만 원 검토 | 4차 1.5%는 15만 원, 최대 5%까지 여유 40만 원, 현금 20만 원. 가장 작은 금액을 적용 |
| 같은 가격·가이던스, 유기 ARR 미확인 | 자료 대기 | 근거가 채워질 때까지 추가 0원 |
| 같은 가격·가이던스, 유기 ARR +7.9% | 반증 재검토 | 4차 미충족에 더해 보고서의 8% 미만 반증 조건 성립. 축소량 미정 |
| 380달러, 논지 유지, 첫 축소 미검토 | 가치에 따른 축소 검토 | 원문의 첫 1/3 축소안을 대조. 다음 검토일에도 같은 차수를 기계적으로 반복하지 않음 |

현재 평가액과 차수 기사용액을 따로 기록한다. 예를 들어 이미 4차를 전부 사용했다면 이후 하락으로 종목 한도에 여유가 생겨도 같은 4차의 추가액은 0이다. 일부 사용했다면 미사용 잔액만 검토한다. 380달러에서의 축소 예시는 검토 개시까지이며 여러 축소선을 한 번에 넘거나 축소 분모가 불명확할 때는 기존 계획과 이력을 먼저 대조한다.

사후에는 같은 보유 상태에서 아무 변경 없이 유지한 대조군과 선택안을 비교한다. 추가·축소한 물량, 현금수익, 거래비용, 배당을 포함해 차이를 측정하고 하락 방어가 목적이었다면 해당 구간의 손실도 함께 본다. 이번 비교가 검증하는 것은 조건별 판단의 일관성이다. 실제 성과 측정은 후속 관측 과제다.
