# 기업·시장 근거를 연구 판단으로 연결하는 계약 v0.1

2026-11-20 · 설계 초안 · 실행 코드·정책 변경 없음

## 목적과 기존 구조

[기존 아키텍처](architecture.md)의 ResearchOpinion을 구체화한다. 기업·시장 분석에서 제안의 채택·보류·기각 이유를 추적할 수 있게 하는 연구다. 여기서 **채택은 연구 후보로 채택**한다는 뜻이며 투자 승인·비중 확정·주문이 아니다. 기존 매수/관망/회피 라벨을 이 세 상태로 치환하지 않는다.

기존 investment-research의 사업·재무·가치·반대 논지, thesis-tracker의 가정·반증, decision-ledger의 판단·회고를 연결한다. 새 Skill이나 별도 원장을 만들지 않는다. 실제 기업 분석 시 canonical Skill의 데이터 검증과 보고서 절차를 그대로 적용한다.

## 판단에 필요한 근거

| 항목 | 기록할 내용 | 부족할 때 |
| --- | --- | --- |
| 기준 시점 | 판단 cutoff, 공시/가용/조회시각, 문서·버전·출처 | 시점 불명은 보류; cutoff 이후 자료는 제외 |
| 핵심 논지 | 누가 왜 돈을 지불하는지, 현금흐름·경쟁우위로 이어지는 경로 | 단순 호재 목록이면 보류 |
| 주장과 증거 | 각 주장 ID에 실제 관측/추정/해석, 찬반 증거와 품질 연결 | 누락을 긍정 또는 부정 증거로 취급하지 않음 |
| 가치와 가격 | 통화·주식수·현금/부채 기준, 시나리오 가정·가치 범위, 가격 기준시각 | 범위/핵심 가정 미검증이면 보류 |
| 반증 | 관측할 지표·출처·판정 조건·점검 계기, 핵심/보조 가정 구분 | 반증 불가능한 논지는 보완 요청 |
| 대안 | 현상 유지·추가 조사·대체 후보와 기회비용 | 대안 없는 확신 점수로 채택하지 않음 |
| 남은 불확실성 | 미해결 질문, 판단을 바꿀 자료, 재검토 계기 | 해소 책임/방법을 기록 |

시장 전망은 금리·환율·수요 변화가 기업 가치에 영향을 주는 **조건부 시나리오**로 연결한다. ‘시장이 좋다’는 이유로 기업 가치 검증을 생략하지 않는다. 모형이 없는 확률·목표가·안전마진 기준은 임의 생성하지 않는다. 정성 별점을 성공확률로 변환하지 않는다.

## 판단 순서와 경계

1. 증거의 출처·시점·단위·정합성을 확인한다. 중요한 충돌이 해소되지 않았거나 미래 정보가 섞이면 해당 입력을 제외하고 보류한다.
2. 사용 가능한 증거로 핵심 논지의 성립과 반증을 따로 평가한다. 신뢰할 수 있는 핵심 반증이 확인되면 현재 제안을 기각한다. 주가 하락 자체만으로 논지 반증을 선언하지 않는다.
3. 논지가 유효해도 현재 가격에서 가치·하방·대안의 설명이 부족하면 보류한다. 가격 조건 미충족과 기업 논지 훼손은 다른 이유로 기록한다.
4. 필수 근거가 충분하고 핵심 반증이 없으며 가격과 대안 비교가 설명되면 연구 후보로 채택할 수 있다. 작성자와 검토자는 해석 차이를 남기며 자동 합산 점수로 결정하지 않는다.
5. 별도 운용 검토에는 정책 검증과 사용자 승인이 필요하다. 현재 IPS DRAFT이므로 연구 채택으로 운용 가능 상태를 만들지 않는다.

보류는 ‘틀렸다’는 뜻이 아니고, 기각은 기업의 영구 제외가 아니다. 새 증거가 나오면 이전 기록을 보존한 새 버전으로 재심한다. 일반적인 프로젝트 ‘진행’ 승인을 종목 채택·실거래 승인으로 연결하지 않는다.

## 최소 판단 카드 템플릿

다음은 문서 템플릿이며 구현된 JSON Schema나 기존 CLI 입력 형식이 아니다.

- 식별: 연구 ID / 버전 / 기업·시장 / 원 보고서 경로 / 작성자·모델 / 작성시각 / 판단 cutoff
- 증거 목록: 주장 ID / 사실·추정·해석 / source/document ID / 공표·가용·조회시각 / 단위·통화 / 반대 증거 / 신뢰 한계
- 논지: 핵심 가정 / 현금흐름 연결 / 반증 조건 / 반증의 현재 상태
- 가치: 가격 기준시각 / 시나리오·가정 / 계산 산출물 / 가치 범위 / 민감도 / 대안
- 연구 판단: 채택·보류·기각 / 이유 / 가장 강한 반론 / 판단을 바꿀 조건 / 재검토 계기
- 경계: policy_status=DRAFT / investment_approval=없음 / 실제 주문=없음

자료가 없으면 ‘미확인’으로 둔다. 원 보고서의 `**판단**`, `**실행 계획**`, `## 실행 정보` 라벨 및 원장 형식은 유지한다. 실제 후속 구현은 별도 부록/어댑터로 연결하고 파서 회귀 테스트를 통과해야 한다. 연구 카드의 채택 여부를 기존 원장에 매수로 자동 기록하지 않는다.

## 합성 사례에 대한 설계 검토

아래는 실제 기업·시장 데이터나 실행된 Python 테스트가 아니다. 계약의 기대 동작을 검토한 사례다.

| 사례 | 입력 조건 | 기대 판단 | 이유 |
| --- | --- | --- | --- |
| A | 호의적인 논지지만 주요 재무 공시 시점 불명 | 보류 | 당시 알 수 있었는지 확인 불가 |
| B | 충분한 자료에서 핵심 경쟁우위 가정이 반증됨 | 기각 | 좋은 가격만으로 핵심 논지 반증을 상쇄하지 않음 |
| C | 논지 유지, 현재 가격의 안전마진 근거 불충분 | 보류 | 사업 평가와 가격 평가를 분리 |
| D | 필수 근거·가격·대안 검토 완료, 핵심 반증 없음 | 연구 채택 가능, 운용 차단 | 정책 DRAFT와 연구 의견은 독립 |
| E | 가격 하락만 관측, 펀더멘털 신규 자료 없음 | 기존 논지 유지 여부 미확인·새 제안 보류 | 하락만으로 기각 또는 추가매수하지 않음 |
| F | 사후 수익은 좋지만 당시 핵심 가정은 반증됨 | 기존 판단 오류를 회고 | 결과가 좋았다는 이유로 근거를 수정하지 않음 |

## 다음 완료 단위

공개자료 기업 한 건을 선정해 판단 카드와 기존 보고서를 함께 작성하고, 독립 출처·시점·재무 산술 검증 결과를 첨부한다. 자료가 부족하면 보류까지가 유효한 결과다. 반대 논지 검토와 ‘어떤 새 사실이 판단을 바꾸는가’를 반드시 남긴다. 이 사례를 통해 필드의 누락·중복을 확인한 후 필요할 때만 어댑터와 Python 테스트를 구현한다.

평가 대상은 우선 근거 추적 가능성·미래정보 배제·반증 일관성이다. 실제 사례가 쌓이기 전 정확도나 투자성과 개선을 주장하지 않는다. 사후 가격 수익과 논지 적중은 분리하며 기존 판단 원장 성과를 비용 포함 포트폴리오 CAGR/Sharpe/Sortino로 간주하지 않는다.
