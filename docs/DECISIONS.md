## 기록 변경 규칙

- 사용자가 선택한 항목은 당시 답변의 의미보다 넓혀 해석하지 않는다.
- **거버넌스·연구 방향에 대한 승인**은 **실제 투자정책 또는 주문의 승인**과 구별한다.
- 새 결정에는 날짜, actor(사용자/설계 제안), 변경 전후, 이유, 영향 받는 IPS/문서/코드, 관련 PR을 기록한다.
- 기존 결정 수정 시 삭제 대신 `SUPERSEDED by D-xxx`로 연결하고 과거 내역을 보존한다.
