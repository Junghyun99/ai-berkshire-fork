# ai-berkshire Roadmap

## SAA 최신 진행 요약 — 2026-10-30

[Phase 2-3 잠정 결론](../reports/saa/20261030-phase2-3-conclusion/README.md): 연구 구현·잠정 비교·계산 검증 수행, 공식 한국 국채 장기 TR/과거 가용시점/최종 배분/PR 통합 미완료. 전체 완료로 닫지 않는다. 다음 Phase 2-4는 납입·인출과 TWR/MWR 계약 → 계좌별 적격/세금/유동성 근거 → 레버리지 일별 경로 모델 설계 순서다. 사용자 금액·한도는 미정이며 최신 규정 확인은 구현 시 별도 수행한다. 기존 P0/P1/P2 개발 축과 최초 인계 표는 아래에 보존한다.

## P0: 단기 (1-2개월)

### 한국/중국 데이터 소스 연동
- DART OpenAPI, akshare, East Money 등 무료 데이터 소스 연동
- 한국 주식·중국 A주의 재무 데이터, 시세 커버
- 기존 Skill은 수정 불필요, 데이터 계층 확장만으로 가능

## P1: 중기 (3-6개월)

### HTML 보고서 출력
- Markdown 기반 위에 HTML 보고서 형식 추가
- 다크 모드, 내비게이션 바, 차트 시각화 지원
- 보고서의 전파성과 읽기 경험 향상

### 다단계 깊이 모드
- `lite`: 5분 속성 판단, 밸류에이션 구간과 핵심 결론을 빠르게 제시
- `standard`: 현재 기본 모드, 완전한 멀티 Agent 리서치
- `deep`: 교차 검증과 역사적 유추를 추가한 기관급 깊이

### 다종목 횡단 비교
- 2-4개 종목의 동일 차원 횡단 대결 지원
- 동종 산업 기업 밸류에이션 벤치마킹
- 비교 매트릭스와 우선순위 제안 출력

## P2: 장기 (6개월+)

### 테스트 커버리지
- 핵심 도구(financial_rigor.py 등)에 단위 테스트 추가
- Skill 출력에 회귀 테스트 추가
- 반복 개선이 기존 기능을 깨뜨리지 않도록 보장

### 포트폴리오 수준 분석
- 보유 포트폴리오 건강도 평가
- 산업/지역 집중도 분석
- 상관관계 리스크 탐지

### 다음 실행 우선순위

1. GitHub 최신 PR 상태/기존 코드·계약·테스트 및 CI 점검.
2. Phase 2-2 데이터 출처·인증/API/라이선스 확인 및 검증 데이터 수집(실험 데이터와 구분).
3. Phase 2-3 코드의 가용시점 누수, 지수 총수익·FX, 공분산·거래비용 가정 개선 및 동일 조건 OOS 비교.

**프로젝트 경계:** Work는 연구/코드/PR/리포트를 수행할 수 있어도 자동으로 투자자 승인, 정책 효력 발생, 실제 주문을 수행해서는 안 된다.
