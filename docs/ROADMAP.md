# ai-berkshire Roadmap

## 개별주 구성 비교 — 2026-11-27

같은 주식 예산에서 종목 동일가중과 공통 위험 그룹 동일가중의 집중도 및 충격 손실을 합성 사례로 비교했다. 다음은 동일 시점의 실제 후보 보고서로 노출 근거를 확인하는 작업이다. [비교 결과](../reports/integration/20261127-equity-sleeve/README.md)

## 주식 비중과 개별주 구성 — 2026-11-27

자산배분 연구로 전체 자산 중 주식 비중을 검토하고, 그 안을 기존 분석 스킬로 선별한 개별주로 구성한다. 특정 종목을 정하기 어렵고 테마 노출이 필요할 때 지수·테마 ETF를 검토한다. 다음 연구는 후보 조합, 비중 배정, 집중도·중복 노출 및 재검토 기준이다. 두 합성 구성의 비중 산술을 검증했다. 실제 목표비중은 미정이다. [연결 사례](../reports/integration/20261127-opinion-allocation/README.md)

## 두 번째 연결 사례와 보완 결정 — 2026-11-22

[어도비 대조](../reports/integration/20261122-handoff-repeat/README.md)에서 비중 분모 누락과 차수 조건의 문장 분산이 반복됨을 확인했다. 기존 파서는 전체 상태와 괄호 조건을 보존하므로 현재는 확장하지 않고 [작성·전달 규칙](../methodology/fund-management/skill-reuse-and-handoff.md)을 보완했다. 형식 검사 오류 0·과거 형식 경고 1, 계획 일치 및 합성 형식 assertion 3개 확인. 금융 재검증·전체 테스트는 미실행이다.

다음은 기존 연구 의견을 연구용 자산배분 시나리오 한 건에 연결해 가능/보완 필요를 구분하는 작업이다. 미정 비중이나 정책값을 만들지 않는다. 기존 기업 보고서·Skill·원장·Python은 유지했고 IPS는 DRAFT다. 아래 ‘다음’은 당시 이력이다.

## 기존 보고서 연결 검증 후 다음 작업 — 2026-11-22

[첫 연결 사례](../reports/integration/20261122-existing-report-handoff/README.md)에서 기존 파싱/계획 일치와 관련 테스트 55개 통과를 확인했다. 의미 불일치와 비중·반증·감사 버전 연결의 보완 항목 H01~H06을 기록했다.

1. 다른 기존 보고서 한 건에서 H01~H04 반복 여부 대조.
2. 원 작성 규칙 보완으로 해결할 항목과 기계 판독 계약의 최소 확장이 필요한 항목 구분.
3. 코드 확장이 필요하면 기존 라벨·CLI를 보존하는 변경과 회귀 테스트를 별도 PR로 작성.

새 기업 가치평가와 실제 계좌 관리로 범위를 넓히지 않는다. 아래 첫 사례 작업은 완료했으며 정책·자료·미래 평가 미결은 유지한다.

## 현재 우선순위 — 2026-11-22

D-019에 따라 [기존 Skill 재사용과 연결 범위](../methodology/fund-management/skill-reuse-and-handoff.md)를 우선한다. 기업·산업 분석과 종목 판단을 새로 구현하지 않는다.

1. 기존 분석·판단·실행계획·추적·원장 기능 대조 — 문서/코드 정의 정적 검토 완료.
2. 기존 보고서의 원 판단·검사·반증·비중 의미를 후속 정책/자산배분 입력에 대응 — 다음 작업.
3. 실제 확인된 반복 누락에 한해 기존 파서/검사를 호환 확장하고 회귀 테스트 — 필요 시 후속.

#109 기업 리서치 초안은 독립 과제이며 선행조건이 아니다. 공식 자료·빈티지(#53/#54), 미래 평가(#55/#99), 정책 선택(#56)은 별도 추적한다. 실제 계좌 관리·주문 실행은 현 범위 밖이고 IPS는 DRAFT다. 아래 절은 이전 연구 순서의 이력이다.

## 현재 우선순위 — 2026-11-20

D-018에 따라 자산배분의 현재 탐색 사이클을 [잠정 정리](../reports/saa/20261120-allocation-handoff/README.md)하고 기업·시장 분석을 채택·보류·기각 판단으로 연결하는 연구로 이동한다. Phase 2 전체 완료나 최종 SAA 승인은 아니다.

1. [연구 판단 계약](../methodology/fund-management/research-decision-contract.md): 근거·논지·가치·반증·대안과 판단 연결, 합성 사례 검토 — 이번 문서 초안.
2. 실제 기업 한 건: 기존 Skill로 공개자료 수집·검증 후 판단 카드 적용 — 다음 작업.
3. 사례에서 드러난 누락을 보완하고 필요한 어댑터/검증만 구현 — 후속.

공식 자료·빈티지(#53/#54), 미래 평가(#55/#99), 정책 선택(#56)은 별도 추적한다. 미래 평가 36개월을 기다리지 않으며 자동 실행 일정도 만들지 않는다. 계좌 연결·잔고 대조·주문 실행은 범위 밖이다. 아래 절은 이전 연구 순서의 보존 기록이다.

## 현재 연구 방향 — 2026-11-14

사용자가 투자기법·의사결정 연구를 우선하고 실제 계좌 관리를 추후 단계로 지정했다(D-017). 연구에는 공개 시장자료와 출처가 표시된 시뮬레이션을 사용한다. 실계좌 명세 수집·증권사 연결·잔고 대조는 향후 운용 과제다.

다음 연구 후보는 ‘어떤 조건에서 자산배분 제안을 채택하거나 보류할 수 있는가’다. [Phase 2-3 잠정 결론](../reports/saa/20261030-phase2-3-conclusion/README.md)에서 비교군·비용·기간·자료 한계를 추출하고, 각 판단의 근거와 반증 조건을 정리한다. 동일가중 대비 최적화의 개선이 일관되는지, 주식 노출을 고정한 방어자산 비교에서 위험지표가 엇갈릴 때 어떤 판단이 가능한지를 구분한다. #53·#54는 시장자료 품질과 과거 가용성, #55는 향후 평가 설계에서 이어간다. 주지표와 채택 문턱은 연구 후보이며 승인된 정책값은 미정이다.

## SAA 최신 진행 요약 — 2026-10-30

[Phase 2-3 잠정 결론](../reports/saa/20261030-phase2-3-conclusion/README.md): 연구 구현·잠정 비교·계산 검증 수행, 공식 한국 국채 장기 TR/과거 가용시점/최종 배분/PR 통합 미완료. 전체 완료로 닫지 않는다. 다음 Phase 2-4는 납입·인출과 TWR/MWR 계약 → 계좌별 적격/세금/유동성 근거 → 레버리지 일별 경로 모델 설계 순서다. 사용자 금액·한도는 미정이며 최신 규정 확인은 구현 시 별도 수행한다. 기존 P0/P1/P2 개발 축과 최초 인계 표는 아래에 보존한다.

## P0: 단기 (1-2개월)

### 한국/중국 데이터 소스 연동
- DART OpenAPI, akshare, East Money 등 무료 데이터 소스 연동
- 한국 주식·중국 A주의 재무 데이터, 시세 커버
- 기존 Skill은 수정 불필요, 데이터 계층 확장만으로 가능

## P1: 중기 (3-6개월)

### HTML 보고서 출력
- Markdown 기반 위에 HTML 보고서 형식 추가
- 다크 모드, 내비게이션 바, 차트 시각화 지원
- 보고서의 전파성과 읽기 경험 향상

### 다단계 깊이 모드
- `lite`: 5분 속성 판단, 밸류에이션 구간과 핵심 결론을 빠르게 제시
- `standard`: 현재 기본 모드, 완전한 멀티 Agent 리서치
- `deep`: 교차 검증과 역사적 유추를 추가한 기관급 깊이

### 다종목 횡단 비교
- 2-4개 종목의 동일 차원 횡단 대결 지원
- 동종 산업 기업 밸류에이션 벤치마킹
- 비교 매트릭스와 우선순위 제안 출력

## P2: 장기 (6개월+)

### 테스트 커버리지
- 핵심 도구(financial_rigor.py 등)에 단위 테스트 추가
- Skill 출력에 회귀 테스트 추가
- 반복 개선이 기존 기능을 깨뜨리지 않도록 보장

### 포트폴리오 수준 분석
- 보유 포트폴리오 건강도 평가
- 산업/지역 집중도 분석
- 상관관계 리스크 탐지
