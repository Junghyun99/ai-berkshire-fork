# 버핏 가치투자 매수 전 Checklist

$ARGUMENTS 에 대해 버핏 가치투자 매수 전 Checklist 분석을 수행한다.

**지원하는 입력 형식**: 단일 또는 복수 회사, 쉼표/공백으로 구분. 예: `텐센트, 마오타이, 엔비디아` 또는 `NVDA AAPL MSFT`

## 실행 절차

### 1단계: 입력 해석, 분석 대상 회사 전부 식별

$ARGUMENTS 에서 모든 회사명/코드를 해석한다. 각 회사에 대해 확정한다:
- 회사 정식 명칭, 종목코드, 상장 거래소
- 비상장 회사면 "비상장"으로 표기하고 간단히 설명 (간접 투자 경로가 있는지). 전체 Checklist는 생략

### 1.5단계: AI 리서치 편향 사전 경고

각 회사에 대해 "정보 풍부도"를 빠르게 등급화(A/B/C)하고 보고서에 표기한다:

| 등급 | 판단 기준 | Checklist에 미치는 영향 |
|------|---------|-----------------|
| A등급 | 상장 오래됨, 데이터 풍부 | 정상 실행하되 "컨센서스 함정" 경계 — 모든 지표가 명확해 보인다고 정말 확실한 것은 아니다 |
| B등급 | 데이터 제한적, 추산 필요 | 추산 지표마다 신뢰도 표기, "좋은 사업" 판단 시 데이터 신뢰성을 가중 고려 |
| C등급 | 정보 극도로 희소 | 6관문 표를 억지로 채우지 말고 "데이터 부족으로 판단 불가"를 정직하게 표기, 검증 가능한 핵심 질문에 집중 |

**핵심 원칙**: Checklist의 목표는 **나쁜 선택의 배제**다. C등급 회사에서 "데이터 부족"은 "미통과"도 "통과"도 아니다 — AI가 표를 못 채운다고 부결로 판정하지 말고 "회색 지대, 1차 정보 보완 필요"로 정직하게 표기해야 한다.

돤융핑의 말: "이해 못한다"에는 두 가지가 있다 — 사업이 너무 복잡해서 정말 이해 못하는 것과, 아직 시간을 들여 보지 않은 것. AI 리서치의 한계는 "자료가 적음"과 "이해 못함"을 혼동하기 쉽다는 것이다.

### 2단계: 병렬 데이터 수집

먼저 회사마다 `python3 tools/fact_sheet.py {종목코드}` 로 팩트시트(확정 수치표)를 만들어 각 Agent에 넘긴다. 수익성·밸류에이션·재무 건강의 정확한 수치는 이 표가 기준이며, 다른 출처 값이 다르면 불일치로 표기하고 맞춘 숫자를 만들지 않는다. `데이터 없음`은 추정으로 채우지 않는다.

Task 도구로 **회사마다** 독립 백그라운드 Agent를 띄워 데이터를 수집한다 (모든 회사 동시 병렬 실행). 각 Agent의 수집 항목:

1. **수익성**: ROE (5-10년 추세), 매출총이익률, 순이익률, 잉여현금흐름
2. **밸류에이션 데이터**: 현재 주가, 시가총액, PER(TTM), 선행 PER, PBR, 배당수익률
3. **성장 추세**: 최근 3년 매출/이익 성장률
4. **재무 건강**: 부채 수준, 자본지출 수요, 현금 보유, 순현금/순부채
5. **경쟁 구도**: 시장 점유율, 주요 경쟁사, 점유율 변화 추세
6. **해자 증거**: 브랜드/전환비용/네트워크 효과/규모의 경제/기술 장벽의 구체적 증거
7. **경영진 기록**: CEO 이력, 핵심 결정, 지분, 자본 배분 기록
8. **최신 동향**: 최근 6개월 중대 이벤트 (실적, M&A, 규제, 경영진 변동 등)

### 3단계: 회사별 6관문 Checklist 실행

상장된 각 회사에 대해 차례로 6개 관문을 통과시킨다:

---

#### 제1관문: 나는 이 사업을 이해하는가 (능력의 범위)

반드시 답할 것:
- [ ] 이 회사가 무엇으로 돈을 버는지 한 문장으로 말할 수 있는가?
- [ ] 10년 후에도 높은 확률로 무슨 사업을 하고 있을까?
- [ ] 어떤 핵심 변수가 성패를 좌우하는가?
- [ ] 이 산업에 대한 인식은 깊은 리서치에서 왔는가, 주워들은 것인가?

**채점 기준** (★1-5):
- ★★★★★: 비즈니스 모델이 지극히 단순 명확, 10년 확실성 높음 (예: 마오타이 — 술 빚어 술 판다)
- ★★★★☆: 모델은 명확하나 기술 장벽이 있어 일정한 전문 지식 필요
- ★★★☆☆: 모델은 이해 가능하나 10년 확실성이 낮고 산업 변화 빠름
- ★★☆☆☆: 사업 라인이 복잡하거나 산업이 격변 중이라 미래 예측 어려움
- ★☆☆☆☆: 완전히 능력 범위 밖

**하드 부결**: 돈 버는 방식조차 설명 못하면 바로 "능력 범위 밖, 분석하지 않음"으로 표기.

---

#### 제2관문: 이것은 좋은 사업인가 (경제적 특성)

데이터로 말한다. **핵심 지표는 반드시 도구로 정밀 계산**:

```bash
python3 tools/financial_rigor.py verify-valuation \
  --price {주가} --eps {EPS} --bvps {주당순자산} --fcf-per-share {주당 FCF} --dividend {주당 배당}
```

| 지표 | 이 회사의 수치 | 참고 기준 | 판단 |
|------|-----------|---------|------|
| ROE (5년 평균) | | >15% 우수, >20% 탁월 | |
| 매출총이익률 | | >40%면 가격결정력 시사 | |
| 잉여현금흐름 | | 지속 플러스, ≈순이익 | |
| 자본지출 강도 | | 경자산이 중자산보다 우위 | |
| 부채 수준 | | 이자부 부채/순이익 <3년 | |

**채점 기준** (★1-5):
- ★★★★★: ROE>25%, 고마진, 강한 FCF, 경자산, 저부채 (전부 충족)
- ★★★★☆: 4개 충족
- ★★★☆☆: 3개 충족
- ★★☆☆☆: 2개 충족 또는 추세 악화
- ★☆☆☆☆: 대부분 미달 또는 FCF 지속 마이너스

---

항목별 점검:

| 해자 유형 | 보유 여부 | 구체적 증거 | 넓어지는가 좁아지는가? |

| 비용/규모 우위 | | | |
| 기술/특허 장벽 | | | |

추가 검증: 경쟁사에게 100억을 주면 이 사업을 복제할 수 있는가?

**채점 기준** (★1-5):
- ★★★★★: 다중 해자가 중첩되고 넓어지는 중
- ★★★★☆: 최소 하나의 강한 해자가 있고 안정적
- ★★★☆☆: 해자는 있으나 깊이가 부족하거나 추세 불명
- ★★☆☆☆: 해자가 침식되는 중
- ★☆☆☆☆: 뚜렷한 해자 없음

#### 제4관문: 경영진을 신뢰할 수 있는가 (사람 요인)

| 점검 항목 | 평가 |
|--------|------|
| 정직성 (약속 vs 이행) | |

| 오너 마인드 (창업자 vs 전문경영인) | |

**채점 기준** (★1-5):
- ★★★★★: 창업자가 키를 잡고, 자본 배분 탁월, 이해관계 완전 일치
- ★★★★☆: 경영진 우수하나 작은 흠 존재
- ★★★☆☆: 경영진 합격이나 지배구조에 잠재 리스크
- ★★☆☆☆: 정직성 또는 지배구조 문제 존재

|------|------|---------|------|

| PBR | | | |

추가 검증 (**반드시 도구로 정밀 계산, 암산 금지**):

### 4단계: 거울 테스트

각 회사에 대해 거울 테스트 문장을 작성한다:

> "나는 ___원에 ___회사를 매수한다. 이유는:
> 1. 이 사업의 본질은 ___이고, 나는 그것을 이해한다;
> 2. 해자는 ___이며, 넓어지고/좁아지고 있다;
> 3. 경영진은 ___하며, 신뢰할 수 있다/없다;
> 4. 현재 가격은 내재가치의 ___수준이고, 안전마진이 충분하다/없다;
> 5. 내가 틀리더라도 하방 리스크는 통제 가능/불가능하다. 왜냐하면 ___."

**5문장을 온전히 못 쓰면 = 사지 않는다.** "통과" 또는 "미통과"를 명확히 표기.

---

### 5단계: 빠른 부결 리스트

각 회사를 항목별로 점검하고, 하나라도 걸리면 바로 "부결"로 표기한다:

- [ ] 이 회사가 어떻게 돈을 버는지 설명할 수 없다
- [ ] 3년 연속 잉여현금흐름 마이너스이고 개선 기미가 없다
- [ ] 경영진에게 정직성 오점이 있다
- [ ] 경쟁 우위가 비가역적으로 침식되고 있다
- [ ] "다음 매수자가 더 높은 가격을 내는 것"에 기대야 돈을 번다 (폭탄 돌리기)
- [ ] 이 투자가 0이 되는 결과를 감당할 수 없다
- [ ] 매수 이유가 주로 "다들 사니까" 또는 "요즘 잘 오르니까"다
- [ ] 매수 이유를 200자 이내로 명확히 쓸 수 없다

| | | ★☆☆☆☆ | ★☆☆☆☆ | ★☆☆☆☆ | ★☆☆☆☆ | ★☆☆☆☆ | |

### 7단계: 최종 결론과 파일 저장

각 회사에 명확한 결론을 준다 (회피하지 않는다):
- ✅ **Checklist 통과** (X/6 관문) — 심층 리서치 단계로 진입 가능
- ❌ **Checklist 미통과** — 어떤 레드라인에 걸렸는지 설명
- ❓ **회색 지대** — 핵심 쟁점이 무엇이고, 투자자가 스스로 판단해야 할 것이 무엇인지 설명
- N/A — 비상장/매수 불가

Checklist 결론과 별도로, 회사마다 **결론 라벨 줄**을 고정 형식으로 쓴다(판단 원장이 읽는 줄, `.claude/skills/decision-ledger/SKILL.md` 1-1). 복수 회사 보고서는 맨 앞에 `**종목**` 필드를 붙인다:
```
**종목**: 텐센트 | **판단**: 관망 | **확신도**: ★★★ | **내재가치**: - | **반증 조건**: ...
```
**판정 규칙** (TradingAgents의 Research Manager·Portfolio Manager 판정 규칙):
1. 상충하는 근거가 있다는 것만으로 `관망`을 고르지 않는다. 어느 쪽이 더 강한지 가리고, 이긴 정도로 확신도(★)를 정한다.
2. `관망`은 저울질한 뒤에도 증거가 정말 균형이거나 근거가 너무 빈약할 때만. 그때는 무엇이 균형을 이뤘는지 쓴다.
3. 단호해 보이려고 방향을 지어내지 않는다. 자료의 양, 서술 순서, 과거 판단의 결과에 끌리지 않는다.
4. **가장 강한 반대 논거**를 하나 골라 데이터로 답한다. 답하지 못하면 그 사실을 쓰고 확신도를 낮춘다.

**판정 기준** (`investment-team` SKILL.md 7단계 규칙 8~11과 같은 기준. `report_check.py` 가 검사하며 작성일 2026-11-25 이후 ❌):
5. **라벨 내재가치 = 판정에 실제로 쓴 가치.** 보수적 가치(정상화 이익·비관 시나리오)로 판단했다면 라벨 범위도 그 가치로 쓴다. 판정 근거에 아래 줄을 쓴다(회피 또는 내재가치 미산정 `-` 이면 생략. 단일 회사 보고서는 맨 앞 `**종목**` 필드를 뺀다. 복수 회사는 회사마다 한 줄씩):
   `**안전마진**: 기준가 88,200원 · 중앙 112,500원 → 21.6% | **요구 안전마진**: 10 + max(U_v 15.6, U_e 21.9) + L 0 = 31.9%`
   `**이익 변동**: 영업이익 최대 하락 73.1% (2016→2017, 10개 해, DART) → U_e 21.9% | **재무 위험**: 이자보상배율 65.72배(2025) → L 0`
   두 줄은 `python3 tools/mos_inputs.py calc {종목코드} --as-of {데이터 시점} --iv-low {하단} --iv-high {상단} --price {기준가}` 출력을 그대로 옮긴다(손으로 계산하지 않는다; 복수 회사 보고서는 두 줄 모두 앞에 `**종목**: 회사명 |`).
   - **현재 안전마진 X** = 1 − 기준가 / 라벨 내재가치 중앙(`report_check.py` 가 ±1%p 안에서 다시 계산).
   - **요구 안전마진 M** = clip(10% + max(U_v, U_e) + L, 하한 15%, 상한 45%) — 종목마다 계산한다. 업종별 일괄 기준표는 쓰지 않는다.
     - **10%**: 어떤 모델이든 남는 추정 오차.
     - **U_v (추정 오차)** = (내재가치 상단 − 하단) / 2 / 중앙. 라벨 범위에서 나온다.
     - **U_e (이익 변동)** = 최근 10개 회계연도 이익의 고점 대비 최대 하락률 × 0.3, 상한 30%. 이익은 비금융 영업이익(법인세·평가손익 같은 일회성 제외), 금융업(은행·보험·증권·지주) 지배주주 순이익. 한 해라도 적자면 하락률 100%, 연간 이익이 5개 해 미만이거나 재무 원본을 받을 수 없으면 U_e 30%(다른 출처로 계산했으면 `--u-e`·`--note` 로 넣고 출처를 적는다).
         - **초기 적자 제외**: 그 이전에 흑자 해가 한 번도 없던 적자(사업 초기 적자)는, 첫 흑자 해부터 적자 없이 5개 해 이상 이어졌으면 계산 구간에서 뺀다. 흑자였다가 적자로 돌아선 해(업황 하강·사업 악화)는 그대로 하락률 100%다.
         - **회계 조정(가산)**: 현금이 나가지 않은 회계 항목 5종만 이익에 더할 수 있다 — 인수 무형자산 상각, 금융업 투자손익(차감), 영업권·무형자산 손상, 인수 IPR&D 비용, 세법 개정 일회성 법인세. 연도별 금액과 출처를 `reports/decision-mos-adjustments.csv` 에 적으면 `mos_inputs.py` 가 자동으로 반영하고 `**조정 근거**:` 줄을 함께 출력한다(보고서에 그대로 옮긴다). 반복 항목(상각·투자손익)은 계산 구간 모든 해의 금액이 있어야 하고(한 해라도 없으면 조정하지 않는다 — 적자 해만 고치는 체리피킹 방지), 일회성 항목은 발생한 해만 적고 출처에 '그 외 연도 없음'을 쓴다. 구조조정 비용 등 목록 밖 항목은 더하지 않는다.
     - **L (재무 위험)** = 비금융: 최근 연도 이자보상배율 8배 이상 0, 3~8배 +5%p, 3배 미만·영업적자 +10%p, 이자비용이 없으면 0. 금융업(은행·보험·증권·지주): 레버리지(총자산/지배주주 자기자본) 5배 미만 0, 5~10배 +5%p, 10배 이상 +10%p, 자산·자본 미확보 +10%p. 이유: 금융업은 10년 구간에 신용 사이클이 없으면 U_e 가 0에 가깝게 나오는데(2016~2025 한국 은행 순이익 최대 하락 0~6%), 레버리지 13배면 자산 1% 손실이 자본 13% 손실이 된다(금융위기 때 BAC 적자, JPM −64%, MS −59% — SEC 원본).
     - max(U_v, U_e) 인 이유: 정직하게 넓게 잡은 범위에는 이익 변동이 이미 들어 있어 더하면 같은 위험을 두 번 깎는다. U_e 는 범위를 비정상적으로 좁게 적었을 때의 바닥이다(2026-11 원장: 범위 폭 중앙값이 업종과 무관하게 14~15%, 마이크로소프트 4.7%).
   - **분할 매수 가격** = 내재가치 중앙 × (1 − 안전마진), 안전마진 1차 M − 10%p / 2차 M / 3차 M + 10%p.
6. **재리서치면 가치 변경을 분해한다.** `show {티커}` 에 이전 판단이 있으면:
   `**종목**: 텐센트 | **가치 변경**: 이전 193,000~214,000원(2026-10-28) → 이번 133,000~198,000원 | **중앙 변화**: -18.4% = 데이터 -5% + 가정 -13.4%`
   - 데이터 변화 = 새로 확정된 숫자를 이전 가정에 넣었을 때의 변화, 가정 변화 = 정상화 이익·배수·순현금 인정분·산식을 바꾼 나머지.
   - 가정 변화가 ±10% 이상이면 `**가정 변화 근거**:` 줄 필수. "주가가 내려서"는 근거가 아니다(가치가 가격을 따라가는 것).
7. **관망이면 사유를 하나 고른다** — `**종목**: 텐센트 | **관망 사유**: 가격|균형|확인 대기 — 설명`
   - **가격**: 좋은 사업, 가격만 문제. 현재 안전마진이 요구 안전마진 이상이면 쓸 수 없다(반려). 그때는 `매수`를 다시 검토한다.
   - **균형**: 강세·약세 근거가 정말 맞섰다. 어느 논거끼리 균형인지 쓴다.
   - **확인 대기**: 판단을 가른 변수가 다음 실적·이벤트에서 확인된다. 기다리는 이벤트와 시점(예: 4Q26 대손, 2027-02)을 쓴다. 이미 요구 안전마진으로 반영한 불확실성을 확인 대기로 한 번 더 깎지 않는다(불확실성은 한 번만).
8. **내재가치는 표준 산식과 교차 검증한다.** `python3 tools/intrinsic_value.py calc {종목코드} --as-of {데이터 시점} --trade-currency {거래 통화}` 출력 줄을 판정 근거에 그대로 옮긴다; 복수 회사는 두 줄 앞에 `**종목**: 회사명 |`:
   `**종목**: 텐센트 | **내재가치 산식**: B 경기순환(정상화 이익 × PER) | 비관 … / 중립 … / 낙관 … | 범위 L~H KRW`
   - 도구는 유형을 자동 분류한다 — A 일반(2단계 오너어닝스 DCF, 할인율 USD 9%·KRW 10%), B 경기순환(10년 하위3·평균·상위3 영업이익률 × 현재 매출, PER = 시장 장기 PER(미국 16·한국 10) × 0.6/0.8/1.0), C 금융(정당 PBR = (ROE − 2%) / (COE − 2%) × BPS), E 가정 의존형(자동 계산 불가 — 사유가 줄에 찍힌다). 범위 = (비관+중립)/2 ~ (중립+낙관)/2.
   - **라벨 내재가치는 여전히 분석가 범위다.** 공식은 기준선이다(대체 여부는 원장 정산이 쌓인 뒤 데이터로 정한다).
   - 라벨 중앙이 공식 중앙과 **±50% 넘게** 다르면 `**종목**: 텐센트 | **공식 괴리 근거**:` 줄에 어느 가정이 다른지(성장률·할인율·정상 마진·시장 할인·결산 이후 급변 등)와 그 근거 데이터를 쓴다. 공식이 시장가보다 훨씬 높게 나오면(예: 한국 금융 정당 PBR ≈ 0.9 vs 시장 0.5) "시장은 왜 그만큼만 쳐주는가"를 판정 근거·반증 조건에서 다룬다 — 공식에 시장 할인을 넣지 않는다(시장가를 정당화하는 순환 논리가 되므로).
   - `report_check.py` 가 산식 줄과 괴리 근거를 검사한다(작성일 2026-11-28 이후 ❌).

Checklist 결과와 판단의 대응:
- 통과 + 제5관문 충족(현재 안전마진 ≥ 요구 안전마진) → `매수`
- 통과지만 현재 안전마진 < 요구 안전마진 → `관망`(관망 사유: 가격), 회색 지대 → `관망`(균형 또는 확인 대기)
- 미통과(레드라인) → `회피`
- N/A → 라벨과 원장 기록 생략

완전한 보고서를 CLAUDE.md 명명 규칙에 따라 저장한다: 단일 회사 `reports/{회사명}/{회사명}-checklist-{YYYYMMDD}.md`, 복수 회사 `reports/다중회사비교-checklist-{YYYYMMDD}.md`.

저장 후 형식을 검사하고(`FAIL`이면 라벨 줄·실행 정보를 고친다), 회사마다(N/A 제외) 판단 원장에 기록한다(`.claude/skills/decision-ledger/SKILL.md` 1-2):
```bash
python3 tools/report_check.py {보고서 경로}
python3 tools/decision_ledger.py add --ticker {종목코드} --name {회사명} --from-report {보고서 경로}
```
판독 실패(`NO_DATA`)면 값을 손으로 채우지 말고 라벨 줄을 고쳐 다시 실행한다.
분석 전에는 회사마다 `python3 tools/decision_ledger.py show {티커}` 로 과거 판단을, `python3 tools/decision_ledger.py lessons --ticker {티커} --tag {산업} --market {시장}` 으로 종목을 넘어선 과거 교훈을 확인한다(같은 문서 1-3·1-4). 교훈은 점검 항목이다 — 해당하는 교훈은 결론 근거에 반영 여부를 한 줄로 쓴다.

## 출력 형식 요구사항

1. 회사마다 독립된 장으로 구성: 6관문 점수표 + 핵심 데이터 표 + 핵심 리스크 (3-5개) + 거울 테스트 + 명확한 결론
2. 복수 회사일 때는 마지막에 총괄 비교표 첨부
3. 모든 점수는 ★기호 사용 (★1-5), 반 별 없음
4. 데이터에는 출처와 시점을 표기하고, 추정값에는 "추정"을 명기
5. 글 말미에 버핏의 명언으로 맺는다: "투자의 제1원칙은 돈을 잃지 않는 것이다"
   그 뒤 맨 끝에 `## 실행 정보` 절을 둔다(형식: `.claude/skills/decision-ledger/SKILL.md` 1-1b, 스킬 `investment-checklist`)
6. 언어 스타일: 직접적이고 예리하게, 군말 없이. 버핏/멍거/돤융핑의 어록을 곁들여 코멘트

## 핵심 원칙

- **놓칠지언정 틀리지 않는다**: Checklist의 목표는 나쁜 선택의 배제이지, 최고를 찾는 것이 아니다
- **능력 범위를 정직하게 마주한다**: 모르면 모른다고 말하고, 억지로 분석하지 않는다
- **안전마진은 생명선이다**: 좋은 회사도 비싸게 사면 돈을 잃는다
- **거울 테스트는 건너뛸 수 없다**: 이유를 명확히 말할 수 없으면 사지 않는다. 예외 없다
