# 내재가치 표준화 계획 (v0, 2026-11-27)

> 상태: 0~2단계 진행 중. 기준값은 아래 **기본값**으로 먼저 계산하고, 2단계 비교 보고서를 본 뒤 확정한다.
> 관련: 요구 안전마진 공식(`tools/mos_inputs.py`), 판정 규칙 8~10(`.claude/skills/investment-team/SKILL.md`).

## 1. 왜

- 지금 내재가치에는 정해진 공식이 없다. 버핏 관점 보고서(02)가 방법을 고르고, `financial_rigor.py three-scenario` 는 계산 검산만 한다.
  보고서 85개 중 정상화 이익 66 · three-scenario 55 · EV/EBITDA 40 · DCF 29 · ROE·PBR 27 · 역DCF 19 · SOTP 10 · 오너어닝스 5 · DDM 2.
- 결과: 같은 회사도 실행마다 값이 흔들린다(삼성전자 3주 사이 중앙 −22%, 대부분 가정 변경). 범위 폭(U_v)도 분석가가 정해
  요구 안전마진 계산 전체가 그 판단에 묶인다. 같은 업종 안에서도 방법이 섞여 비교가 어렵다.

## 2. 목표

1. **재현성** — 같은 데이터·같은 가정이면 같은 값.
2. **범위의 정의** — 라벨 하단~상단을 시나리오 값으로 정의(임의로 좁히거나 넓히지 못함).
3. **판단은 정해진 칸에서만** — 기본값을 바꾸려면 "가정 조정"으로 기록·근거. 재리서치 때 가치 변경 분해(규칙 9)가 기계적으로 나온다.

## 3. 유형 자동 분류

| 유형 | 판별(원본 데이터) | 기본 방법 |
|---|---|---|
| C 금융 | DART 업종코드 / SEC SIC 6000~6799 | 정당 PBR(잔여이익) |
| B 경기순환 | 10년 영업이익 최대 하락 ≥ 50% 또는 흑자→적자 전환 | 정상화 이익 × PER |
| E 가정 의존형 | 최근 5년 평균 FCF ≤ 0 | 매출·마진 명시 DCF(수기 가정) |
| A 일반 | 그 밖 | 2단계 오너어닝스 DCF |
| D 지주·복합 | 수동 지정 | 사업부별 합산(SOTP, 수기) — 4단계 |

분류 변경은 근거를 적는다(`**유형**: B (자동: A, 사유: …)`).

## 4. 유형별 산식

**A 일반 — 2단계 오너어닝스 DCF**
- 기준 현금흐름 OE₀ = 최근 5년 평균(영업현금흐름 − CapEx − 주식보상비용)
- 1단계(5년) 성장: 비관 0% / 중립 = 10년 매출 CAGR × 0.5 / 낙관 = 10년 매출 CAGR(상한 15%)
- 2단계 영구성장: 비관 1% / 중립 2% / 낙관 3%
- 할인율 r: 기본값 USD 9% · KRW 10%
- 주당가치 = (DCF 합 + 순현금) / 희석주식수

**B 경기순환 — 정상화 이익 × PER**
- 정상 이익 = 현재 매출 × 영업이익률 × (1 − 세율 22%(KRW)·21%(USD))
  - 영업이익률: 비관 = 10년 하위 3개 해 평균 / 중립 = 10년 평균 / 낙관 = 상위 3개 해 평균
- PER: 비관 8 / 중립 12 / 낙관 15
- 주당가치 = (정상 이익 × PER + 순현금) / 희석주식수

**C 금융 — 정당 PBR**
- 정당 PBR = (ROE − g) / (COE − g), 주당가치 = 정당 PBR × BPS
- ROE: 비관 = 10년 하위 3개 해 평균 / 중립 = 10년 평균 / 낙관 = 최근 3개 해 평균
- COE: USD 9% · KRW 10%, g = 2%

**E 가정 의존형** — 매출 경로·목표 마진·도달 연도를 반드시 명시. 원장에서 따로 집계.

## 5. 라벨 범위 규칙

| 안 | 라벨 범위 | U_v 성격 |
|---|---|---|
| (가) | 비관 ~ 낙관 | 대부분 상한 45% 근처로 감 |
| **(나) 기본값** | (비관+중립)/2 ~ (중립+낙관)/2 | 시나리오 차이의 절반 — U_e 와 겹침을 줄임 |
| (다) | 중립의 할인율 ±1%p 민감도 | 순수 추정 오차, 사업 위험은 U_e 가 전담 |

## 6. 리포트·검사 연동 (3단계)

- `tools/intrinsic_value.py` 출력 두 줄을 리포트에 옮긴다:
  `**내재가치 산식**: B 정상화 PER | 비관 … / 중립 … / 낙관 … | 범위 L~H` · `**가정 조정**: 없음`(또는 항목·기본값·조정값·근거)
- 가정 조정은 `reports/{회사명}/valuation-inputs.json` 에 남긴다. 재리서치 때 이 파일 대조로 데이터 변화 vs 가정 변화가 자동 분해된다.
- `report_check.py` 가 산식 줄을 원본으로 재계산해 라벨 범위와 대조하고, 근거 없는 가정 조정을 반려한다.
- 다른 방법(EV/EBITDA·역DCF 등)은 교차 검증 칸에만 쓰고 라벨 범위에 섞지 않는다.

## 7. 단계

| 단계 | 할 일 | 산출물 |
|---|---|---|
| 0 데이터 확장 | 순현금(현금·단기금융 − 차입금), 희석주식수, 주식보상비용, 10년 매출·OCF·CapEx 를 DART·SEC 수집에 추가 | 수집 함수·테스트 |
| 1 도구 | A·B·C 와 분류기, 시나리오, 라벨 범위 | `tools/intrinsic_value.py`·테스트 |
| 2 원장 비교 | 원장 87종목 공식 vs 분석가 범위, 유형 분포·차이·기준값 민감도 | 비교 보고서 — **기준값 확정** |
| 3 스킬 적용 | 세 스킬 밸류에이션 절 교체, report_check, 원장 재계산 | PR |
| 4 확장 | D(SOTP)·E 템플릿, 원본 없는 시장 수기 입력 | PR |

**기준값 원칙**: 매수 종목 수가 원하는 숫자가 되도록 맞추지 않는다. 할인율·PER 같은 기준값은 외부 근거(시장 평균·금리)로 정하고 결과를 받아들인다.

## 8. 정할 것

1. 할인율·COE·영구성장률 — 고정값(기본값) 또는 10년 국채금리 + 5%p(FRED)로 매번 계산
2. 경기순환 PER 표 — 기본값 8/12/15
3. 라벨 범위 규칙 — 기본값 (나)
4. 가정 조정 허용 폭 — 예: 성장률 ±5%p, PER ±3배; 넘으면 반려 또는 경고
5. 적용 범위 — 기존 원장 재평가 또는 신규 리포트부터
